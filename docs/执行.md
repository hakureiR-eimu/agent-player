# 执行

全局唯一的现状文档：做到哪了、下一步是什么、平台实测出什么结论。翻动最快；"是什么"看各主题的 requirements 和 design，"现在干到哪"只看这里。

## 当前阶段

三步走（2026-10-21 重构）：先跑活单个 agent（本地），再多 agent 上飞书（大群聊天、拉群私聊），最后才接入游戏（开局、记忆演化、agent 操作）。前两步都不绑游戏进程，agent 活在"游戏开始以前"的设定里；游戏接入最复杂，隔离到最后，不拖住前两步。阶段二开头仍按 2026-10-20 的定案，先用假 bot 打薄链路排平台风险。

## 阶段一：单个 agent 本地跑活

不碰飞书、不碰游戏；world/state/ 是空的，设定就是游戏还没开始。

1. [ ] 建 agents/ 模板和 GBR 实例（profile / world / memory 三区）
2. [ ] 写 profile：system.md（通用提示词）+ country.md（从 资料/主要国家/GBR/介绍.md 取）
3. [ ] 搭本地试跑环境：终端版飞书工具（见 [游戏agent/design](游戏agent/design.md) 的"本地试跑"）
4. [ ] 跑通报到：agent 读 profile，在终端大群报到说第一句话
5. [ ] 打磨几轮：语气、随发生随记 memory、翻 world/chat 旧账
6. [ ] 玩一小段单人戏（你扮演其他国家，纯聊天没有游戏），看 memory 自然长成什么样，再定要不要固化格式

## 阶段二：多 agent 上飞书（不绑游戏）

设定仍是游戏开始以前：没有游戏状态，agent 只是活着、在飞书上聊天。先用假 bot 排平台风险，再上真 agent。

7. [ ] 飞书侧：按"一国一应用"建第一个应用，bot 进大群
8. [ ] 运行时最小版：收群消息 → 递给假 agent（固定回复的小脚本）→ 发回群里
9. [ ] 实测下面表里的待验证项
10. [ ] 两个假 bot 进同一个群，测互见；bot 建群后拉别的 bot 进群
11. [ ] 防死循环最小档选型（bot 不回 bot / 白名单 / 限速，按调研的三档先例选）
12. [ ] 真 agent 接进链路（GBR 先上）：你在大群和它聊，看人格、记账在真平台上不变形
13. [ ] 拉起第二个国家（建文件夹、装 profile、拉会话，做成一套动作），多会话并跑；互见互达、排队打包这时受力
14. [ ] 拉群私聊：你把 agent 拉进小群聊；agent 用 create_group 自己拉群也在这测

## 阶段三：游戏接入

设定从"游戏以前"切到"游戏进行中"：接入游戏、开局、记忆随局演化、agent 操作游戏。

15. [ ] 游戏接入调研与定形：能否从外部读写维多利亚3进程、readGame/writeGame 的形状（[游戏接入](游戏接入/requirements.md) 的问题清单在这消化）
16. [ ] 建局脚本：拷资料、建文件夹、拉会话、发开局轮；网页控制台、DM 建大群也在这上（[多agent运行时](多agent运行时/requirements.md) 的开局流程在这落地）
17. [ ] 开一局：开局形势第一次写进 world/state/，绑定游戏进程，agent 读形势、开始操作游戏，memory 随局演化
18. [ ] 多国开一局：大群外交、小群密谈、游戏操作一起受力
