# 多 agent 运行时：需求

## 职责

1. 启动并拉起网站：运行时启动时就带起一个网站（网页控制台）。开局、拉起 agent 都在网页上操作。
2. 拉起 agent：在网页上点"拉起 agent"，选择要拉起哪些国家；每个 agent 是一个 Claude Agent SDK 的 session（同一个进程里的多个会话，不是独立进程），一个 session 扮演一个指定的主要国家。
3. 建目录并初始化：拉起时创建这场游戏的局文件夹，写入不可变状态，创建各国文件夹（结构见下）。
4. 接入飞书：把每个 agent 接进给定的大群，支持小群。具体实现见 [飞书接入](../飞书接入/requirements.md)。
5. 绑定游戏进程：为 agent 提供 readGame / writeGame 两个接口，先做空实现。具体见 [游戏接入](../游戏接入/requirements.md)。
6. 实现所有工具：agent 只做决策和调用工具；飞书收发、readGame/writeGame 等工具的实现都在运行时里。

优先级：4（接飞书）高，5（接游戏）低。

## 目录结构

一局游戏一个局文件夹，多级结构：

```
局文件夹/              ← 表示这场游戏
  不可变/              ← 所有 agent 的不可变状态，初始化时写入，之后只读
    （通用：身份、能力、开局形势，一份）
    （国家介绍，一国一份）
  GBR/                 ← 该国 agent 自己维护的可变内容，文件夹名用国家 tag
  FRA/
  ...
```

## 开局流程

1. 启动运行时，运行时拉起网站。
2. 在网页上点"拉起 agent"，勾选要拉起的国家。
3. 运行时创建局文件夹；先创建不可变文件夹，写入 agent 的不可变状态。
4. 为每个选中的国家创建自己的国家文件夹。
5. 拉起 agent：创建会话，提供初始上下文。

## 生命周期

- 开局：在网站上手动拉起。
- 一局结束：手动结束。
- 中途出问题：session 报错，重新拉起该 session 即可。

## 不可变内容的准备

- 内容由 Claude 写，用户审核定稿。
- 国家资料存放在 `资料/主要国家/` 下，以维多利亚3的国家 tag 作为文件夹名（如 `资料/主要国家/GBR/`），tag 是国家、文件夹、agent 的统一绑定标识。
- 开局前备好；拉起 agent 时从中取用，写入局文件夹的不可变文件夹。主要国家名单与 tag 对照见 `资料/主要国家/README.md`。
