# 背景

> 为什么做这个项目。这是最稳定的文档，写完之后几个月内不应该大改。

## 一句话愿景

> 让维多利亚3的开局列强不再是死板的脚本 AI，而是有性格、有盘算、能合纵连横的 agent 玩家——像 8 个真人一样跟你谈判。

## 立论：为什么是大战略/4X/SLG

作者是资深 Paradox 玩家。判断 **4X、大战略策略、SLG 是最适合接入 agent 玩家的游戏类型**：

1. **外交本身就是语言游戏**：这类游戏的核心乐趣之一——结盟、威胁、许诺、背刺——天然是谈判，正是 LLM 的主场；而操作层面的微操反而次要。
2. **原生 AI 最薄弱的恰是外交**：传统策略 AI 的外交是僵硬的数值规则（态度 −50 就拒绝），毫无"博弈感"，玩家无法与它"讨价还价"。
3. **状态可枚举、动作可枚举**：大战略的游戏状态和外交动作都是离散、结构化的（条约、关系、宣战借口），比动作游戏更适合接口化。
4. **风味素材充足**：历史背景、国家性格、大国关系有海量可写素材，"角色书"能写出真正的味道。

社区讨论也印证这一点：对"LLM 做大战略 AI"的质疑集中在操作延迟与决策规模，而共识是 **LLM 最适合先做外交与谈判**——正是我们的切入点。

## 我们想做什么

基于 **Victoria 3（维多利亚3）** 制作游戏 agent：

1. **全面接入**：开局所有非玩家列强（约 8 个，以 1836 开局实际名单为准）各接入一个 agent，执行合纵连横的外交。
2. **角色化**：每个 agent 拥有自己的**角色书**（国家人设：性格、口吻、历史包袱）与**国家目标**（战略诉求、底线），尽可能增加风味与智能，模拟真实的大国外交。
3. **三通道沟通**：玩家与 agent 通过**飞书**交流——
   - **公屏**（公开外交）：所有国家可见的声明与表态
   - **私聊**（秘密外交）：一对一密谈、许诺与威胁
   - **拉群**（集团外交）：多国集团内部协调
4. **游戏接口化**：把游戏状态接口化，agent 能读取局势（关系、条约、战争、排名……）；同时暴露受限的操作接口，agent 可借此操作游戏——**第一版只开放外交操作，主打外交沟通**。

## 为什么难（核心挑战）

这些挑战直接决定技术选型，也是 brainstorm 的主要方向：

- **游戏侧无现成 API**：V3 没有官方运行时外部接口，"状态读取 + 操作注入"的桥接层要自建（候选路径见《参考/游戏接入-victoria3》）。
- **战略一致性**：纯 LLM 谈吐好但容易"说着说着忘了图什么"，CICERO 的启示是语言层与战略层要分层。
- **背叛与信誉**：外交的灵魂是可信的承诺与可信的背叛；后续研究显示 CICERO 偏不合作——需要信誉机制而非放任。
- **成本与节律**：约 8 个 agent 高频对话，token 消耗可观；V3 是可暂停实时制，agent 的决策节奏需要设计。
- **安全**：防止玩家（或 agent 之间）用 prompt injection 劫持；防止语言层的甜言蜜语绕过游戏规则层（给不给好处必须由游戏逻辑说了算）。

## 非目标（Non-goals）

明确不做的事，防止范围蔓延：

- **不做通用框架**：只为 Victoria 3 服务，不做多游戏适配层
- **不做全操作 agent**：不做经济、内政、军事微操——第一版只做外交
- **不替代传统 AI**：agent 只接管列强的"外交人格"，其余行为仍用游戏原生 AI
- **不做游戏内 UI**：沟通走飞书，不在游戏里做聊天界面
