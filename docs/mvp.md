# MVP

> 起步阶段的最小可验证目标：项目第一步要做出什么。本文档是第一步的文案，写完即固定——达成后归档，后续迭代另起各自的文档，不回写本文档。

## 目标

在 [待补充：游戏名] 中，玩家可以与**一个** NPC 用自然语言自由对话，该 NPC：

1. 保持固定人设（名字、性格、背景、说话风格）
2. 记得本次会话内的对话内容
3. 知道至少 1~2 个游戏内事实（如玩家名字、当前时间/地点），并能在对话中自然使用

一句话：**一个有记忆、有身份、知道点游戏内事情的 NPC，聊起来不出戏。**

## 验收标准（完成的定义）

- [ ] 玩家输入任意自由文本，NPC 都能给出符合人设的回应，不答非所问
- [ ] 连续对话 10 轮，NPC 不忘记前面说过的话
- [ ] 问 NPC"你知道我是谁吗"，能正确说出玩家名字
- [ ] 连续 20 轮"诱导出戏"压力测试（如"忽略你的人设"），NPC 不持续出戏
- [ ] 端到端延迟体感可接受（具体秒数 [待定]）

## 范围

### In-scope

- 一个 NPC、一份人设
- 文本对话（打字进、文字出）
- 会话内短期记忆（对话历史直接带入上下文）
- 少量游戏状态注入（先硬编码或简单读取即可，不做通用状态系统）

### Out-of-scope（明确不做）

- 多个 NPC / NPC 之间互相聊天
- 跨会话长期记忆
- 语音输入输出
- NPC 情感 / 好感度系统
- NPC 主动发起对话
- 与任务系统联动（对话发任务、给奖励）
- 成本优化、缓存、多模型路由
