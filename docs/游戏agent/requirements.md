# 游戏 agent：需求

单个 agent 的形态：状态 + 动作。一个 agent 是一个 Claude Agent SDK 的 session，由运行时拉起。

## 状态

### 不可变状态（薄，运行时提供）

初始化时由运行时写入，放在局文件夹的不可变文件夹里，agent 运行期间只读、不能改。

- 通用部分（所有 agent 相同）：
  - 身份：告诉 agent 它扮演的是《维多利亚3》的一名玩家。
  - 能力：告诉 agent 它可以操作游戏，可以去飞书跟其他玩家沟通。
  - 开局形势：游戏开局时的国际形势。
- 国家特有部分：所扮演国家的介绍。

### 可变状态（agent 自己维护）

放在自己国家的子文件夹里，agent 自己读写。仿照一个真实的维多利亚3玩家的自我认知：

- 我的目标：想达成的战略目标。
- 我的当前状态（关于自己）：仿照 4X 游戏的设定，四种当前状态（暂拟：探索、扩张、开发、征服）；agent 自己判断并切换，基于当前状态进行不同的操作。
- 我的外交状态（关于其他人）：对每个其他国家的关系、印象与立场。

## 动作

agent 只做决策和调用工具，工具的实现都在运行时里。

1. 文件动作：读写自己文件夹内的文件，由 Claude Agent SDK 提供——用 grep 搜索内容，用 read、write、edit 读取和编辑。可变状态就存这些文件里。
2. 飞书动作：在大群和小群里发消息，用于和其他玩家（真人或 agent）交流。具体动作清单见 [飞书接入](../飞书接入/requirements.md)。
3. 游戏动作：readGame 读游戏状态、writeGame 操作游戏状态，空接口占位。见 [游戏接入](../游戏接入/requirements.md)。

## 要回答的问题

1. 四种当前状态的操作细则：什么信号触发状态切换，每种状态下 agent 该做什么。
2. 可变状态怎么存：国家文件夹里文件怎么组织（一个文件还是多个、什么格式、多久写一次）。
3. 不可变状态以什么形式给到 agent：写进 session 的系统提示，还是作为文件放局根文件夹让 agent 自己读——涉及 session 的工作目录定在哪、能不能读父级目录。
