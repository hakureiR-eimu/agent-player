**Gujarat** is a [formable country](https://vic3.paradoxwikis.com/Formable_country) in western India.

Gujarat can form [India](India.md) (BHT).

## Formation

| ![Ambox outdated info.png](https://central.paradoxwikis.com/images/thumb/6/65/Ambox_outdated_info.png/22px-Ambox_outdated_info.png) | Please help with verifying or updating this section. It was last verified for version 1.12. |

Gujarat can be formed by the following countries when they fully own the core state, Gujarat.

| Country | Capital | Primary Cultures | State Religion | Tier | Type | Core states |
|---|---|---|---|---|---|---|
| **Baroda** | Gujarat | Gujarati, Marathi | Hindu | Principality | Unrecognized | Split state in Gujarat |
| **Bhavnagar** | Gujarat | Gujarati | Hindu | Principality | Unrecognized | Split state in Gujarat |
| **Dharampur** | Gujarat | Gujarati | Hindu | Principality | Unrecognized | Split state in Gujarat |
| **Idar** | Gujarat | Gujarati | Hindu | Principality | Unrecognized | Split state in Gujarat |
| **Junagadh** | Gujarat | Gujarati, Pathan | Sunni | Principality | Unrecognized | Split state in Gujarat |
| **Kutch** | Gujarat | Gujarati | Hindu | Principality | Unrecognized | Split state in Gujarat |
| **Nawanagar** | Gujarat | Gujarati | Hindu | Principality | Unrecognized | Split state in Gujarat |
| **Palanpur** | Gujarat | Gujarati, Pathan | Sunni | Principality | Unrecognized | Split state in Gujarat |

All of the above exist at start and may be [released](Releasable countries.md) if they cease to exist. Gujarat may also appear as part of a rebellion against the [East India Company](https://vic3.paradoxwikis.com/East_India_Company)

If Junagadh or Palanpur form Gujarat, they retain Sunni state religion

## Gujarati minors

| ![Ambox outdated info.png](https://central.paradoxwikis.com/images/thumb/6/65/Ambox_outdated_info.png/22px-Ambox_outdated_info.png) | Please help with verifying or updating this section. It was last verified for version 1.12. |
|---|---|

The Gujarati minors are all unrecognized powers and have similar basic stats, starting technology, and politics. Each starts with a split state in Gujarat and each is a puppet of [East India](East India.md). They are all Principalities and Hindu, except Junagadh and Palanpur which are Sunni. They generally start with the Zamindars in government with the Hindu Priesthood, Armed Forces, Intelligentsia, and Ryots in opposition, and the remaining interest groups marginalized.

The Hindu Priesthood has the Hindu Moralist ideology instead of the default Moralist. The Petite Bourgeoisie has the Modernizer ideology instead of the default Reactionary. The Intelligentsia has the Constitutionalist ideology instead of the default Republican.

They all start with the following technology and laws:
