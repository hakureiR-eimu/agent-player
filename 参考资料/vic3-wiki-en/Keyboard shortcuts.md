This article is [timeless](https://vic3.paradoxwikis.com/Category:Timeless) and should be accurate for any version of the game.

Keyboard shortcuts, or hotkeys, are used to navigate the menus of Victoria 3. Some keyboard shortcuts can be edited under *Controls* in the *Settings* game menu, and can also be found at $XDG_DATA_HOME/Paradox Interactive/Victoria 3/input_profiles/default.profile. To reset the keyboard shortcuts, rename or delete the file. A few additional shortcuts are defined in the game files at .steam/steam/steamapps/common/Victoria 3/game/gui/shortcuts.shortcuts.

## Default controls

### Panel keys

These keys navigate to specific information panels.

| Key | Icon | Function |
|---|---|---|
| F1 |  | Politics panel |
| F2 |  | Budget panel |
| F3 |  | Buildings panel |
| F4 |  | Market panel |
| F5 |  | Military panel |
| F6 |  | Diplomacy panel |
| F7 |  | Technology panel |
| F8 |  | Cultures panel |
| F9 |  | Population panel |
| F10 |  | Journal |
| F11 |  | Journal |
| Q |  | Ledger |
| ⇧Shift+F1 |  | Outliner |

### Lens keys

These keys control the various map lenses.

| Key | Icon | Function |
|---|---|---|
| Alt+1 |  | Production lens |
| Alt+2 |  | Political lens |
| Alt+3 |  | Diplomatic lens |
| Alt+4 |  | Military lens |

### Other HUD controls

These keys open other specific elements of the HUD.

| Key | Function |
|---|---|
| F | Open location finder |
| B | Open Construction Queue |
| ^Ctrl+B | Pause/Unpause Construction Queue |
| E | Open Current Situation |
| G | Go to Details |
| 🏠 Home | Center on capital province |

### Tab/Window Navigation

These keys control navigation through the open tab or event window

| Key | Function |
|---|---|
| ⇧Shift+1 | Open tab 1 |
| ⇧Shift+2 | Open tab 2 |
| ⇧Shift+3 | Open tab 3 |
| ⇧Shift+4 | Open tab 4 |
| ⇧Shift+5 | Open tab 5 |
| Page Up | Scroll up |
| Page Down | Scroll down |
| C | Confirm |
| ⎋Esc | Close current window |
| Mouse button 4 | Back |

### Game Controls

These keys control various other game settings

| Key | Function |
|---|---|
| ␣ Space or Mouse button 5 | Pause control |
| = or NumPad + | Increase speed |
| - or NumPad - | Decrease speed |
| 1 — 5 | Set game speed 1—5 |
| W ↑ A S D or ← ↓ → | Scroll the map view |
| ⇆Tab | See map overview |

### Music Controls

These keys control the music player

| Key | Function |
|---|---|
| NumPad 8 or Audio Play | Play/Pause Music |
| NumPad 9 or Audio Next | Next Music track |
