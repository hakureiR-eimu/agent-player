**Game rules** are configuration choices available when starting a new game that can alter some game mechanics. Game rules can be saved as presets. Only the *Achievements* game rule affects the player's ability to unlock [achievements](Achievements.md).

The game rules are set at the beginning of the game and can be changed by using the *Switch Country* menu option. The ironman game rule cannot be changed, and changing the achievements game rule has no effect.

## List of game rules

In the following table, the **bold** setting is used by default. The *Learn the Game* [objective](Objective.md) uses *Lenient* AI Behavior and *Low* AI Aggression by default.

| Rule | Setting | Effects |
|---|---|---|
| Achievements | **Allowed** | [Achievements](Achievements.md) can be unlocked during this campaign |
| Blocked | Achievements will *not* be unlocked during this campaign |  |
| AI Behavior towards Players | Lenient | AI countries will act friendlier towards Player countries and treat them more leniently in [diplomatic plays](https://vic3.paradoxwikis.com/Diplomatic_plays) |
| **Standard** | AI countries will view Player and AI countries in the same way, with no special considerations for Players |  |
| Harsh | AI countries will be more suspicious of Player countries' intentions and treat them more harshly in diplomatic plays |  |
| AI Aggression | Low | AI countries will start fewer diplomatic plays and are less inclined to conquer territory |
| **Standard** | AI countries have standard aggression settings based on their strategies |  |
| Harsh | AI countries will start more diplomatic plays and are more inclined to conquer territory |  |
| Loyalties Grace Period | **None** | You bear the full brunt of both [Radicals](https://vic3.paradoxwikis.com/Radical_(pop)) and [Loyalists](https://vic3.paradoxwikis.com/Loyalist_(pop)) right from the start |
| Short | Radical and Loyalist gain starts out low but progressively increases, with full effect 1 year after game start |  |
| Long | Radical and Loyalist gain starts out low but progressively increases, with full effect 5 year after game start |  |
| Extra Long | Radical and Loyalist gain starts out low but progressively increases, with full effect 10 year after game start |  |
| Formable Nations | **All** | Allow implausible and fantasy-esque nations to be [formed](Formable countries.md) |
| Historically Plausible | Allow only historically plausible nations to be formed[1] |  |
| Releasable Nations | **All** | Allow implausible and fantasy-esque nations to be [released](Releasable countries.md) |
| Historically Plausible | Allow only historically plausible nations to be released[2] |  |
| Pop Consolidation (Performance)[3] | None | [Pops](Pops.md) will never consolidate outside Assimilation or Conversion rules, regardless of size. This could greatly harm performance in the mid- to late game |
| Minor | Pops will only consolidate if they are very small and ineffectual. May harm performance in the mid- to late game. |  |
| **Moderate** | Pops may consolidate if they are quite small and have a limited impact on gameplay. |  |
| Aggressive | Given the right conditions even Pops of moderate size may consolidate. May improve performance, but will impact game balance |  |
| Monument Effects | **Enabled** | [Monuments](https://vic3.paradoxwikis.com/Monuments) may produce a variety of different effects depending on its nature, and typically employ pops to do so. |
| Prestige Only | All monuments generate a fixed amount of [prestige](https://vic3.paradoxwikis.com/Prestige) for its country. No monument employ[sic] pops. |  |
| Disabled | Monuments are decorative only. The reward for constructing them is purely visual. |  |
| Flags for Subjects | No Flag Changes | The flags of [subject](Subject.md) countries will *not* change based on who their suzerain is |
| **Allow Flag Changes** | The [flags of subject countries](List of flags.md) may change based on who their suzerain is |  |
| Map Color for Subjects | No Map Color Changes | The map color of subject countries will *not* change based on who their suzerain is |
| **Allow Map Color Changes** | The map color of certain types of subject countries may change based on who their suzerain is |  |
| Fantastical Content | **Enabled** | Allow supernatural or fantastical content during this campaign |
| Disabled | Allow no supernatural or fantastical content during this campaign |  |
| Custom RNG Seed | **Disabled** | The game will automatically set an RNG seed leading to different outcomes on each playthrough. |
| Enabled | Allows setting a specific RNG seed so most random outcomes follow that seed. As a result, initialization and observer games without player interaction will give the same results across multiple playthroughs using tha same seed. |  |
| Dynamic Naming | **Enabled** | States and cities will change their names based on the culture of the country that owns them |
| Disabled | States and cities will not change their names based on the culture of the country that owns them |  |

## Ironman

**Ironman** is a special game rule that disables country switching, entering observer mode and manual saving. The game is saved automatically at regular intervals as determined by the game's settings (by default every month), as well as exiting the game. Unlike in other Paradox games, ironman is not a prerequisite for getting achievements.
