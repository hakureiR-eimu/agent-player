**Dravida Nadu** is a [formable country](https://vic3.paradoxwikis.com/Formable_country) in southern India. It represents a union of the southern Dravidian cultures: Tamil, Telugu, Malayalam, and Kannada.

Dravida Nadu can form [India](India.md) (BHT).

## Formation

Six of the eight core states are needed in order to form Dravida Nadu
Dravida Nadu can be formed by the following countries when they own six of the eight core states and have researched Pan-nationalism.

| Country | Capital | Primary Cultures | State Religion | Tier | Type | Core states |
|---|---|---|---|---|---|---|
| **Bastar** | Central Provinces | Gondi, Telugu | Hindu | Principality | Unrecognized | Split state in Central Provinces |
| **Carnatic** | Carnatic | Tamil | Hindu | Kingdom | Unrecognized | Carnatic Ceylon |
| **Cochin** | Malabar | Malayalam | Hindu | Principality | Unrecognized | Split state in Malabar |
| **Kurnool** | Ceded Districts | Pathan, Deccani, Telugu | Sunni | Principality | Unrecognized | Split state in Ceded Districts |
| **Mysore** | Mysore | Kannada | Hindu | Principality | Unrecognized | Mysore |
| **Pudukottai** | Carnatic | Tamil | Hindu | Principality | Unrecognized | Split state in Carnatic |
| **Travancore** | Malabar | Malayalam | Hindu | Principality | Unrecognized | Malabar |

All of the above except Carnatic exist at start and may be [released](Releasable countries.md) if they cease to exist. Carnatic is formable. If Kurnool forms Dravida Nadu, it retains Sunni state religion.

## Dravidian minors

| ![Ambox outdated info.png](https://central.paradoxwikis.com/images/thumb/6/65/Ambox_outdated_info.png/22px-Ambox_outdated_info.png) | Please help with verifying or updating this section. It was last verified for version 1.10. |
|---|---|

The Dravidian minors are all unrecognized powers and have similar basic stats, starting technology, and politics. Most start with a split state in the Dravidian core states, and each is a puppet of [East India](East India.md). They are all Principalities and Hindu, except Kurnool which is Sunni. They generally start with the Zamindars in government with the Hindu Priesthood, Armed Forces, Intelligentsia, and Ryots in opposition, and the remaining interest groups marginalized.

The Hindu Priesthood has the Hindu Moralist ideology instead of the default Moralist. The Petite Bourgeoisie has the Modernizer ideology instead of the default Reactionary. The Intelligentsia has the Constitutionalist ideology instead of the default Republican.

They all start with the following technology and laws except as noted below:
