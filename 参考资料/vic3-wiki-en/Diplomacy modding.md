### Diplomatic actions

The relevant documents can be found in the diplomatic_actions folder in `/Victoria3/game/common/diplomatic_actions`. Each type of action has its own file.

### Diplomatic plays

The relevant document can be found in the diplomatic_plays folder in `/Victoria3/game/common/diplomatic_plays`. All types of diplomatic plays are saved in the same save game file.

### Secret Goals

The AI can be guided towards certain behaviors towards other nations by using `set_secret_goal` and `set_mutual_secret_goal`. The following are known secret goals:

- antagonize
- befriend
- conquer
- dominate
- none
- protect
