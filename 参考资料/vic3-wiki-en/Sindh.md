**Sindh** is an unrecognized regional power in South Asia. It borders [Makran](https://vic3.paradoxwikis.com/Makran) to the southwest, [Kalat](https://vic3.paradoxwikis.com/Kalat) to the northwest, [Punjab](Punjab.md), and [EIC's](East India.md) protectorates [Bahawalpur](Bahawalpur.md), and [Jaisalmer](https://vic3.paradoxwikis.com/Jaisalmer) to the northeast, and [Marwar](https://vic3.paradoxwikis.com/Marwar), [Palanpur](https://vic3.paradoxwikis.com/Palanpur), and [Kutch](https://vic3.paradoxwikis.com/Kutch) to the southeast.

## Formation

If Sindh ceases to exist, it can be [released](Releasable countries.md) by any country that controls its sole core state.

### Interest groups

Sindh begins with the Zamindars as the sole [interest group](Interest group.md) in government, with the Armed Forces, Sunni Ulema, Ryots in opposition. The Intelligentsia, Trade Unions, Petite Bourgeoisie, and Industrialists are marginalized.

The Petite Bourgeoisie has the Modernizer ideology instead of the default Reactionary. The Intelligentsia has the Constitutionalist ideology instead of the default Republican.

### Diplomacy

Sindh starts with no [treaties](Treaty.md) or diplomatic agreements.

Sindh starts with an active interest in only Bombay, with no additional interests.

[British East India](East India.md) has claims on the state of Sind, which is an existential threat.

### Industry and Resources

**Industry**

Sindh does not have any industry at game start.

**Resources**

Sindh can build many types of plantations including opium, coffee, fabric, sugar, and tobacco. It does not start with any though.

It can build 4 sulfur mines, but doesn't start with any.

## Military

| ![Ambox outdated info.png](https://central.paradoxwikis.com/images/thumb/6/65/Ambox_outdated_info.png/22px-Ambox_outdated_info.png) | Please help with verifying or updating this section. It was last verified for version 1.10. |
|---|---|

Sindh has the Peasant Levies law.

Sindh starts with 23 Battalions and can raise no Conscripts. All Barracks use No Organized Training. The battalions compose a single army.

The army starts without a general.

Sindh does not start with any navy.
