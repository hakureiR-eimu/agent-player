A number of [countries](Countries.md) have **dynamic map colors** when certain conditions are fulfilled. These conditions most often include the country's [laws](Laws.md) and less often the states it owns or its ruler's ideology.[1] Dynamic map colors often overlap with [dynamic country names](Dynamic country names.md) and [dynamic flags](List of flags.md), though not always at a one-to-one correspondence.

## Revolutionary country colors

Revolutionary countries typically use a random map color; if the revolution succeeds, it returns to using the country's default color or whatever dynamic color applies.

## Subject country colors

Subject countries use their top overlord's country color, dynamic or not, if the *Map Color for Subjects* [game rule](Game rule.md) is set to *Allow Map Color Changes*. This overrides any dynamic color that the subject country might otherwise use.

## Country-specific colors

If more than one dynamic color can be applied to a country, only the highest ordered color is applied. The default color is not considered, as that is not strictly a dynamic color.
