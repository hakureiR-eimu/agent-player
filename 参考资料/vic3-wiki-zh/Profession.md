**职业**（Professions）反映了[人口](Pops.md)在其工作的[建筑](Building.md)中所从事的工作类型。人口的职业决定了它的社会阶层，并影响其基础工资、它有资格从事哪些其他职业，尤其是它倾向于支持哪些政治[利益集团](Interest group.md)。投资于能为玩家希望在国家中扶持的职业提供就业机会的产业，是《维多利亚3》“社会构建”玩法的核心。

## 职业类型

共有 15 种人口职业（以及一种失业状态）。这些职业被划分为不同的*社会阶级*，而阶级又根据国家的*社会等级制度*归属不同的阶层。

## 社会等级制度

*社会等级制度*决定了哪些职业或人口属于哪些*社会阶级*，以及各阶级属于哪些*社会阶层*。目前共有三种社会等级制度。除了直接作用于职业外，各种效果和 modifier 也可以施加于各个社会阶级和阶层。

### 基础等级制度

这是默认的社会等级制度，在没有其他社会等级制度适用时生效。

|---|---|---|---|
| 阶级 | 下层阶级 | 中层阶级 | 上层阶级 |
| 职业 | 职员 劳工 机械工 农民 士兵 奴隶 | 学者 官僚 教士 工程师 农场主 军官 店主 | 贵族 资本家 |

## 资质

下埃及州潜在有资质的工程师列表。
资质代表了个体在想要转职时担任特定职业的能力。每个人口对其他每种职业都有一个资质等级。资质基于多种因素按人口规模的比例每月获得，因此较大的人口每月可能有许多个体获得资质，而较小的人口甚至可能需要数月才有一个个体获得资质。[4] 资质可能因个体死亡、转变为其他人口或某些情况下的衰减而失去。当人口中的个体改变职业或以其他方式转变人口时，他们会带走相应比例的资质。此外，他们还会将先前职业的资质带入新职业。

每种职业的资质取决于多种因素，通常是财富和识字率，但当前职业和[接受度](Acceptance.md)也起到一定作用。下表列出了获得表中职业资质的因素；*识字率*是人口的识字率百分比，在计算资质时转换为小数；财富是人口的基础生活水平，不受任何影响生活水平的 modifier 加成。修饰因素仅在获得资质时适用，在资质衰减时不适用。此外，大学会根据其生产方式和吞吐量为资质获取提供额外加成。

| 职业 | 基础资质因素 | 修饰因素 |
|---|---|---|
| 学者 | 若识字率高于 20%，+(识字率−20%)×20 +财富/10 否则 −1 | ×5 为贵族或职员 ×0.1 文化接受度低于 +60 ×0 为农奴制下的农民 |
| 贵族 | 若财富达 15 或以上，+(财富−14)/20 +(财富−20)/5（最低 +0） ×(0.5+识字率/2) 否则 −2 | ×2 为官僚 ×3 为军官 ×5 为农场主或教士 ×0.1 文化接受度低于 +60 ×0 为农奴制下的农民 |
| 官僚 | 若识字率高于 20%，+(识字率−20%)×20 否则 −1 | ×2 为完全接受 ×1.5 为二等公民 ×5 为职员或教士 ×0.1 文化接受度低于 +60 ×0 为农奴制下的农民 |
| 资本家 | 若财富高于 10，+(财富−10)/5 +识字率×2 否则 −2 | ×5 为工程师或店主 ×0.1 文化接受度低于 +60 ×0 为农奴制下的农民 |

| 职员 | +识字率×20 | ×2 为劳工 ×0.1 为农奴制下的农民 |
| 工程师 | 若识字率高于 20%，+(识字率−20%)×10 +财富/20 否则 −2 | ×5 为机械工 ×4 为职员 ×0 为农奴制下的农民 |

## 工作满意度

所有人口都有一个工作满意度分数，代表它们寻找新工作的意愿。工作满意度为正的人口不太可能更换工作场所或迁移，而满意度为负的人口则更有可能这样做。

| 来源 | 数值 |
|---|---|
| 基础 | **−130** |
| 已就业 | **+100** |
| 在政府建筑中就业 | **+50** |
| 近期被雇佣 | **+1000** |
| 收入高于支出 | **+1000** |
| 收入低于支出 | **−100** |
| 生活水平与以下各项之差（每点）： 预期生活水平 州内同阶层平均生活水平 国内同阶层平均生活水平 | — ±3 ±2 ±1 |
| 每高于或低于[标准工资](Vickypedia.md)的百分比 | **±1** |
| 每百分比的更高阶层资质 | **−1** |
| 分红基础 乘以与工资的百分比比率 分红下限 分红上限 | +50 — +0 +250 |

## 雇佣流程

个体会根据其当前职业以及其有资质从事的任何职业被雇佣以填补空缺职位。无法被任何建筑雇佣的人口即为*失业*人口。建筑不能雇佣不具备相关职业资质的人口。

除失业人口外，人口中的一员要迁往另一建筑，必须获得比其当前就业工资至少高 **10%** 的工资。如果新职位属于不同职业，他们还必须具备该职业的资质。

各职业保持（大致）成比例，例如，一座建筑不能只雇佣一整套劳工，除非它同时能雇佣其所需的其他每种职业的至少 90%[5]。反过来说，如果一座建筑将要流失例如大量机械工，它就必须开始解雇所有其他职业，直到比例重新平衡。某些建筑被允许无视比例性雇佣，即所有权建筑。某些职业也无视比例性，即农民、军官和士兵。

建筑可以被补贴（取决于当前的*经济体制*法律），以防止人口因缺乏利润而被解雇。

### 工资

基础工资是一个绝对关键的数值，因为它决定了受雇工人能获得多少钱——从而能花多少钱，生活水平有多高，进而影响迁移吸引力，能赚到多少利润，以及生产的商品成本有多高。

每座建筑都有一个*基础工资*，它乘以每种职业的工资倍率。因此，在基础工资为 £1 时，建筑支付给劳工 £1，机械工 £1.5，工程师 £3，依此类推。由于建筑只能调整其基础工资，所有职业保持相同的比例。此外，根据当前颁布的*公民权*和*国教*法律，人口可能会因[接受状态](Acceptance.md)而被支付更多或更少的工资。

建筑提高基础工资主要是为了在无法以其他方式填补空缺职位时吸引员工。利润非常高的建筑如果员工低于预期生活水平且被接受，也可能提高工资；相反，不盈利和利润中等的建筑会降低工资以恢复盈利能力。因此，人口众多且资质良好的州往往工资较低，至少在该州的建筑雇用了所有人口之前是如此。合格工人数量有限的州平均工资较高。

已合并州中基础工资的全国平均值被称为*标准工资*。它被用作政府出资建筑的基础工资，以及福利金和最低工资的基准。

完全有可能出现这样的情况：

- 某种商品需求量很大，
- 有充足的生产该商品的建筑，
- 有足够的合格工人（甚至是失业的工人），

然而建筑却不雇佣人，因为基础工资太高。在这种情况下，玩家可以等待系统自动重新达到均衡（这可能需要很长时间），或者选择补贴该建筑，这可能代价高昂，且并不能解决根本问题。
