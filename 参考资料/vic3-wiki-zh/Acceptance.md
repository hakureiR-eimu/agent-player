**接纳度（Acceptance）**表示一个人口在一个国家中受到的对待与认可程度。人口的*接纳状态*主要取决于其[文化](Culture.md)和[宗教](Religion.md)相对于该国[公民权与政教关系法律](Power structure laws.md)（在印度则是英国种姓制度法律）的关系。当一个州形成新的文化社群时，该文化的人口会承受 **−30** 的临时接纳度惩罚，并以每月 **0.25** 的速度衰减至 **0**。[事件](Events.md)也会产生影响。

每个人口都有一个 0 到 100 之间的接纳度分数，用于决定其状态。某些法律与修正项的组合理论上可能使接纳度低于 0 或高于 100，但由于接纳度以上述数值为上下限，这不会产生任何效果。

## 接纳状态

| 状态 | 分数 | 迁移意愿 |
|---|---|---|
| 暴力敌视 | 0-19 | 100 |
| 文化抹除 | 20-39 | 100 |
| 公开偏见 | 40-59 | 50 |
| 二等公民 | 60-79 | 20 |
| 完全接纳 | 80-100 | 0 |

共有五个状态等级，从接纳程度最低到最高排列。

每个接纳等级的效果在很大程度上取决于[公民权法律](Power structure laws.md)，例如禁止投票或允许同化，以及对工资、政治力量、可就业建筑以及忠诚派与激进派增长的修正。

不过，也有一些效果不受法律影响。

每个接纳状态都有一个基础迁移意愿，通常人口越被接纳，该数值越低。迁移意愿较高的人口在条件允许时更可能移民海外。

在战争中死亡的人口（无论死于战斗还是损耗）会根据其状态影响厌战度。这会相对被杀人口在交战双方国家的接纳度，对战争双方都产生影响。这种厌战度是在伤亡带来的厌战度之外的额外部分。

文化接纳状态低于公开偏见的鼓动家无法被邀请进入该国。

### 暴力敌视

*“处于此状态的人受到如此公开的蔑视、污名化和迫害，以至于普通民众宁可将其从地球上铲除，也不愿浪费精力和时间将其融入社会。”*

处于此状态的人口有 100 的基础迁移意愿。战争伤亡不会造成额外厌战度。

### 文化抹除

*“处于此状态的人被主流社会踩在脚下，后者的首要目标就是抹除这些人的文化、传统和信仰体系。只有在那之后，主流群体才会开始探索如何将这些同化进主流社会。”*

处于此状态的人口有 100 的基础迁移意愿。战争伤亡不会造成额外厌战度。

### 公开偏见

*“处于此状态的人被允许与社会其他成员共同生活。然而，这种看似中立共存的状态，是以其自身习俗和信仰体系不断受到更高接纳等级者的审视和反对为代价的。”*

处于此状态的人口有 50 的基础迁移意愿。战争伤亡对本国造成 50% 的厌战度，对敌国不造成厌战度。

### 二等公民

*“处于此状态的人在名义上享有大量社会福利。尽管如此，他们仍被社会以从属的方式看待和对待，常常面临歧视、受限的权利，以及有限的资源和机会获取途径。”*

处于此状态的人口有 20 的基础迁移意愿。战争伤亡对本国造成 150% 的厌战度，对敌国造成 50% 的厌战度。

### 完全接纳

*“处于此状态的人是被社会完全接纳的成员，享有无限的社会流动性和稳定的特权。他们的核心价值观、信仰体系和社会经济声望，塑造了其他所有人都向往的社会结构本身。”*

处于此状态的人口有 0 的基础迁移意愿。战争伤亡造成 300% 的厌战度。

## 提示

### 关于公民权法律

- *多元文化*可能是最好的公民权法律，因为它在*公开偏见*等级下也能提供至少 **+40** 的接纳度，尤其适合人口较少的国家，或通过殖民扩张或征服获得了大量文化迥异省份的国家。
- 然而，*多元文化*很难通过，因为它需要*人权*和*禁止奴隶制*作为前提，而且初期[意识形态](Ideology.md)下没有任何[利益集团](https://vic3.paradoxwikis.com/Interest_groups)支持它。在这种情况下，*文化排斥*是一个替代选择，它在*文化抹除*等级下也能提供至少 **+20** 的接纳度。
- 在游戏**初期**，当你作为**未受认可国家**或**以奴隶贸易或遗留奴隶制开局的国家**无法通过*文化排斥*时，*臣民身份*可能是更好的选择，因为它为文化家园提供 **+30** 的接纳度。

### 关于政教关系法律

- *政教完全分离***不是**一个好选择，因为它最多只能提供 **+15** 的接纳度，在实行*多元文化*或*文化排斥*时无法提升接纳等级。
- *信仰自由*通常是更优的选择，因为它为国家宗教的人口提供 **+20** 的接纳度。在*多元文化*下，这合计可以在*二等公民*等级达到基础接纳度 **+60**，且不会对其他信仰的人口施加惩罚。在*文化排斥*下，国教人口的基础接纳度为 **+40**。*信仰自由*还允许改信。
- *国教*不如*信仰自由*有效，因为它会对大多数宗教造成 **−5** 或 **−25** 的接纳度惩罚，很可能使接纳度降至*暴力敌视*或*文化抹除*，而对国教人口 **+25** 的接纳度也无法使其达到比*信仰自由*更高的接纳等级。另一方面，*国教*允许任何接纳等级的人口改信，如果你能通过多种途径叠加改信速率加成，例如宗教大会[强权集团](Power bloc.md)、*宗教学校*、[俄美公司](https://vic3.paradoxwikis.com/Russian-American_Company)等，*国教*也是一个合理的选择。
- *国家无神论*可能是最差的选择，因为它最多只提供 **+15** 的接纳度加成，最坏情况下还会造成 **−10** 的接纳度惩罚。
