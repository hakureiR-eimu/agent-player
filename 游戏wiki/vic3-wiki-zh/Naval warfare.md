虽然战争主要依靠地面部队获胜，但海军力量同样不容忽视。任何拥有海外领土、海外附属国或海外贸易的国家都可能遭到护航船队袭击，这会严重削弱工业，因为海外市场接入会大幅降低，商品无法在各地区之间流通。此外，与海外敌人作战需要运送军队并维持补给线，两者都可能遭到袭击，还可能需要发动海上登陆来开辟陆上战线。最后，仅仅是一支强大海军的存在，就能提升一个国家在世界列强中的地位。

## 舰船

海军单位称为*舰船*（Ships）。舰船通过舰船建造（Ship Construction）建造，由造船厂生产。舰船总是编组成一个或多个称为*舰队*（Fleets）的编制。每艘舰船都需要足够的水兵才能运作。水兵由*海军管理部门*（naval administrations）产生，可以在任何州（而不仅是沿海州）建造。每个满员的海军管理部门产出 1000 名水兵。舰队只有当[海峡](https://vic3.paradoxwikis.com/Strait)控制者允许舰队所有者通行时才能通过海峡。

### 补给舰

补给舰是一种用于为已在海上的军用舰船以及海外陆军提供补给的舰船。为一支海军重新补给需要一定数量的补给舰，而补给不足时舰船会沉没。补给舰建造分配决定了有多少舰船建造被分配到补给舰的生产上。

### 舰船类型

海军单位分为四类：*主力舰*（Capital Ships）、*巡洋舰*（Cruisers）、*雷击舰艇*（Torpedo Craft）和*补给舰*（Supply Ships）。舰队的移动速度由舰队中最慢的舰船决定。其他属性则每艘舰船各自独立，不过舰队界面会显示各属性在整个舰队中的平均值。

在这四大类之下，舰船进一步细分为不同的船体类型，通常按技术进步划分：

- 主力舰：
  - 风帆战列舰（Ship of the Line）
  - 早期铁甲舰（Early Ironclad）
  - 现代铁甲舰（Modern Ironclad）
  - 浅水重炮舰（Monitor）
  - 海防舰（Coastal Defense Ship）
  - 前无畏舰（Pre-Dreadnought）
  - 无畏舰（Dreadnought）
  - 超无畏舰（Super Dreadnought）
- 巡洋舰：
  - 护卫舰（Frigate）
  - 铁甲护卫舰（Iron Frigate）
  - 运兵船（Troopship）
  - 防护巡洋舰（Protected Cruiser）
  - 装甲巡洋舰（Armored Cruiser）
  - 轻巡洋舰（Light Cruiser）
  - 水上飞机母舰（Seaplane Tender）
  - 航空母舰（Aircraft Carrier）
- 雷击舰艇：
  - 鱼雷艇（Torpedo Boat）
  - 鱼雷艇驱逐舰（Torpedo Boat Destroyer）
  - 潜艇（Submarine）
  - 驱逐舰（Destroyer）
- 补给舰：
  - 补给舰（Supply Ship）

## 海区节点

点击比斯开湾海区节点（节点上的三角形表示它已被选中），然后点击海军标签页，就可以看到哪些舰队在该节点上做什么。注意，执行护航任务的舰队也会显示在“沿海巡逻”框中，而这些舰队不会卷入友方袭击舰队与敌方巡逻舰队之间的战斗——因此，如果英国 35 艘的袭击舰队与法国 60 艘的巡逻舰队之间爆发战斗，英国 100 艘的护航舰队不会参战。

舰队在海区节点（海洋上由虚线连接的蓝色或金色圆圈——代表海域和大洋区域）中活动。大多数海区节点连接着若干州区域，放大地图并沿着从节点延伸到各区域港口省份的较细虚线即可看到。

舰队的任务仅在舰队部署到海区后才会生效。

海区节点还在一定程度上决定贸易路线的商船成本和补给线的补给舰成本，路线经过的节点越多，成本越高。

### 存在感

驻扎在海区节点时，舰队以每天 2% 的速度积累*存在感*（presence）。舰队命令的效果会按其在该海区节点的存在感进行缩放。

## 海上登陆

海上登陆需要一支舰队和一两支陆军。陆军可以是随舰队登船的海军陆战队，也可以是为此目的运送的常规陆军，或者两者兼有。如果陆军的投射力量低于目标州的海上要塞登陆防御，则无法发起海上登陆。

一旦登陆得到确认，如果选择了常规陆军，舰队会先在友方沿海州与其会合，然后前往目标州相邻的海区节点。登陆要继续进行，该海区节点必须是无争议的，以便建立滩头阵地。如果有任何投射力量达到进攻方舰队投射力量至少 25% 的防御舰队部署在该海区节点，则该节点处于*争议*状态。一旦陆军登陆，争夺海域便不再有任何效果。
战斗开始需要两周时间。驻扎在该地区总部的守方陆军**确实会**参与海防登陆的防御。但如果发生多处登陆，最好为每一处登陆单独指派陆军，因为驻扎的陆军可能将其所有营投入一场战斗，从而使另一处登陆无人防守。

每有一个非海军陆战队类型的入侵营，就会受到**−25%** 的*海上登陆效率*攻击惩罚。

如果入侵舰队在任何海战中失败，或陆军在目标州领土占领度为 0% 时输掉三场战斗，海上登陆即告失败。随后陆军和舰队将返回其本土总部。

一旦目标州被完全占领，登陆即告成功，并会建立一条新的常规前线。

### 海防工事

[海防工事](https://vic3.paradoxwikis.com/Naval_Fortification) 用于加固沿海州，抵御海上攻击和海上登陆。它们能提供针对海上登陆、封锁和炮击的抵抗力。

## 海战

一支法国巡逻舰队在比斯开湾截住了一支被指派袭击护航船队的英国舰队。注意英国舰队的起始士气很低（它尚未从先前的战斗中恢复过来）。
如果持有对立命令的敌对舰队在同一海域停留足够长的时间，就会发生海战。屏幕上的海区节点上会显示一个圆圈中的锚标志，双方舰队随即交战。舰船不再只有单一的进攻/防御属性对——战斗现在通过上表更完整的属性组来解决（命中率对脆弱性决定命中，船体/船员伤害对装甲决定造成的伤害，暴击几率/倍率提供爆发伤害，护航掩护影响护卫/拦截），但仍分为进攻方（海上登陆/袭击护航船队的拦截方）和防守方（护航船队袭击者/反登陆舰队）。与陆战类似，双方也各有战斗条件，可能对结果产生重大影响。

与陆战一样，海战会持续进行（除非战争先结束），直到一方士气耗尽。

### 分舰队的份额

当前公式：

- 从每一方当前未处于另一场战斗中的舰船开始计算（并非简单的“舰队中可用的分舰队”）。
- 受指挥海军上将的指挥上限限制（为其一半，若低于无指挥官默认值则取无指挥官默认值）；无指挥官的舰队以固定的无指挥官默认值为上限（/Victoria 3/game/MILITARY_FORMATION_COMMAND_LIMIT_NO_COMMANDER = 20）。
- 然后由一个比较该方单舰*侦测*与敌方单舰*可见性*的系数进行调整——相对于敌方舰队的可见性而言侦测能力更强的一方，会有相对更多的舰船投入战斗。这直接与上文舰船表中的侦测/可见性属性相关（水上机母舰和航空母舰的侦测值为 150/300，远超其他所有舰种）。

### 海战条件

海战条件代表海战期间的天气。它们影响交战双方，并在很大程度上受该海域当前[收成状况](Harvest condition.md)（如果有）的影响。除修改战斗属性外，若干条件还会造成周期性的船体或船员伤害，其数值随条件的强度而变化。

| 海况 | 权重，受天气修正 | 效果 |
|---|---|---|
| Calm Waters（风平浪静） | 1 ×10 if Calm Waters | 无战斗修正 |
| Cyclone（气旋） | 0 +15 if Cyclone | −30% 命中率 −30% 速度 −30% 备战度获取 −30% 护航掩护 每八个战斗回合：30 按强度缩放的船体伤害 10 按强度缩放的船员伤害 |
| Fog（雾） | 1 ×10 if Fog | −40% 命中率 −10% 速度 |
| Ice（冰） | 0 +10 if Ice | −20% 速度 每 16 个战斗回合：30 按强度缩放的船体伤害 10 按强度缩放的船员伤害 |
| Rough Waters（波涛汹涌） | 1 ×10 if Rough Waters | −10% 命中率 −20% 速度 每六个战斗回合：5 按强度缩放的船体伤害 1 按强度缩放的船员伤害 |
| Strong Winds（强风） | 1 ×10 if Strong Winds | −20% 命中率 −10% 护航掩护 |
| Tropical Storm（热带风暴） | 0 +10 if Tropical Storm +5 if Cyclone | −10% 速度 −20% 备战度获取 −10% 护航掩护 每 20 个战斗回合：3 按强度缩放的船体伤害 2 按强度缩放的船员伤害 |

### 士气恢复

战斗结束后，分舰队会随时间推移逐渐恢复士气（如果舰船被击沉，也会得到重建）。海军上将的部队有可能在士气尚未完全恢复时就开始另一场战斗。

## 补给

在海外作战的编队依靠[补给网络](https://vic3.paradoxwikis.com/Supply_network)来保持装备和补给。如果敌方舰队袭击补给网络、击沉运输船，这将影响编队的补给，并直接影响部队的士气恢复。例如，如果袭击使补给网络的效率降低了 2%，那么海外部队的士气恢复为 98%。如果补给降低超过 95%，则对组织度施加同等惩罚。例如，一个补给为 80% 的部队将受到 20% 的最大组织度惩罚。

此外，部队所属建筑的[短缺](https://vic3.paradoxwikis.com/Shortage)也会使编队补给降低到同样的结果。

### 损耗

所有动员的编队都会受到损耗，导致人口受伤和死亡。其影响可能相当可观，甚至超过战斗造成的伤亡。编队在其本土总部驻扎时受到的损耗减少**−50%**。

基础损耗为**10%**，损耗造成的伤亡每周从**4%**到**12%**不等。

正在积极参与战斗的营暂时不会受到损耗。
