战争概述
**等级（Rank）**代表一个国家在世界上拥有多大的威望与影响力。一个国家处于什么等级——无论是列强还是未受承认的政权——主要由两个因素决定：*威望*和*承认*。

## 国家等级

国家可以获得七个等级，此外还有一个特殊的第八等级，仅适用于（不可游玩的）[松散联邦](Decentralized nation.md)。按等级顺序排列如下：

| 1. |  | *列强：*这些是最强大、最辉煌的国家，其影响力往往遍及全球，会卷入遥远的冲突。最典型的列强例子是[大不列颠](Great Britain.md)。 |
|---|---|---|
| 2. |  | *主要政权：*这些是地区性强国，往往能决定本地区冲突的走向，并可能在全球范围有一定存在感。主要政权的例子是[尼德兰](Netherlands.md)王国。 |
| 3. |  | *未受承认的主要政权：*这些未受承认的政权足够强大、威望足够高，能在地区舞台上施展影响力，试图抵抗受承认政权的要求，并有望成为获得承认的候选者。未受承认的主要政权的例子是[日本幕府](Japan.md)。 |
| 4. |  | *次要政权：*这些是地区性政权，虽可能对本地冲突的结局有重要影响，但在世界舞台上基本无足轻重。次要政权的例子是[墨西哥](Mexico.md)。 |
| 5. |  | *未受承认的地区政权：*这些未受承认的政权足够强大，能够影响较弱的邻国，并有可能抵抗更强的政权。未受承认的地区政权的例子是[索科托](Sokoto.md)。 |
| 6. |  | *无足轻重的政权：*这些国家通常连影响本地冲突结局的能力都没有，除了周边其他无足轻重的政权之外，任何人都可以放心地无视它们。无足轻重的政权的例子是自由城市[克拉科夫](Krakow.md)。 |
| 7. |  | *未受承认的政权：*这些未受承认的政权通常没有实力对抗除最弱小的受承认政权以外的任何国家，往往只能任凭列强和主要政权摆布，不得不在它们之间周旋以求生存。未受承认的政权的例子是[柬埔寨](Cambodia.md)王国。 |

等级顺序对某些机制很重要，例如[附属国](Subject.md)通常必须低于其宗主国的等级。类似地，条约港只有在所有者的等级高于相邻市场所有者的等级时才生效。所有者仍保留该省份，但只要该州所有者维持相同等级，条约港就处于无效状态。

### 等级收益

一个国家的等级越高，下列收益就越好。这些收益包括：

- 产生更多的影响力容量（使其在开展[外交](Diplomacy.md)和签署[外交条约](https://vic3.paradoxwikis.com/Diplomatic_treaties)时拥有更大的自由度）
- 在[外交博弈](https://vic3.paradoxwikis.com/Diplomatic_plays)中拥有更多的行动点。
- 拥有更高的制衡抵抗力。
- 他国获得其支持的独立时，独立倾向提升更多。

等级在许多其他系统中也起着关键作用，例如[附属国](https://vic3.paradoxwikis.com/Subjects)、[恶名](https://vic3.paradoxwikis.com/Infamy)、外交行动等。

## 威望

关于威望类商品的变体，参见
威望商品
威望代表一个国家对世界的经济、军事和社会影响力的总和。所有国家按威望排序，一个国家要达到某个等级，必须满足该等级的威望阈值，该阈值取决于其与全球平均值或与威望最高国家的百分比的比较。

这意味着两件事：

1. 列强、主要政权等的数量并不固定。
2. 维持和提升国家等级所需的条件会随游戏进程而变化。

一个国家可能因其起始条件而以高威望的列强身份开局，但随后因经济和军事停滞而落后于其他国家，最终沦为次要政权，即使其实际威望数值从未下降。随着游戏进行，由于全球人口、GDP 和技术的增长，绝大多数国家的威望都会随时间推移而提高。

当一个国家的威望足以提升等级时，它会立即晋升。相反，如果威望降到所需阈值的 90% 以下，它将有 365 天时间提升威望，否则将降级。

威望来源有多种，有些固定为一定数值，有些则随其他指标而变化。

- 国家的*层级*提供少量威望。这是特定国家固有的，只能通过组建一个层级更高的新国家来提升。
- 军事力量（包括陆军和海军）会增加威望。军事规模越大、越先进，获得的威望越多。
- 国家的总 [GDP](https://vic3.paradoxwikis.com/GDP)（因而间接包括工业化水平）会带来威望。
- [附属国](https://vic3.paradoxwikis.com/Subjects)根据自身的军事和经济实力为其宗主国贡献威望。相比其为本国产生的威望，这些贡献有所折扣。
- 在[商品](Goods.md)生产上位居全球领先（第一、第二或第三）会为国家带来威望，某些商品比其他商品更具威望。
- 主要[运河](https://vic3.paradoxwikis.com/Canal)和大多数其他[奇观](https://vic3.paradoxwikis.com/Monuments)会给予威望。
- 某些[事件](Events.md)，例如发现南极点或尼罗河源头的探险。它们带来的威望提升可能是永久的，也可能是暂时的。
- 若干[社会技术](Society technology.md)会提供威望倍率。

## 承认

承认代表在位的（主要是欧洲）列强是否视该国为世界舞台上的潜在平等伙伴。

国家在开局时要么是未受承认的，要么是受承认的，未受承认的国家必须获得承认才能完整地攀登等级阶梯。由于未受承认的主要政权是未受承认国家所能达到的最高等级，因此未受承认的国家永远低于列强，即使它们拥有更多威望。

通常情况下，国家不会失去承认。但是，[奥斯曼帝国](https://vic3.paradoxwikis.com/Turkey)若未能完成*欧洲病夫*日志条目，就会失去其初始的受承认地位。此外，如果一个国家获得了承认，随后因任何原因不复存在，之后被[释放](Releasable countries.md)或[重组](Formable countries.md)，重新成立的国家不会保留此前的承认。
