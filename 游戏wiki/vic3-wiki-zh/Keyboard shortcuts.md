本文为[长期有效](https://vic3.paradoxwikis.com/Category:Timeless)文章，适用于游戏的任意版本。

键盘快捷键（hotkey）用于在《维多利亚3》中导航各个菜单。部分键盘快捷键可以在游戏菜单的*设置*（*Settings*）中的*控制*（*Controls*）选项下进行修改，也可以在 $XDG_DATA_HOME/Paradox Interactive/Victoria 3/input_profiles/default.profile 中找到。要重置键盘快捷键，重命名或删除该文件即可。还有一些额外的快捷键定义在游戏文件 .steam/steam/steamapps/common/Victoria 3/game/gui/shortcuts.shortcuts 中。

## 默认控制

### 面板按键

这些按键用于跳转到特定信息面板。

| 按键 | 图标 | 功能 |
|---|---|---|
| F1 |  | 政治面板 |
| F2 |  | 预算面板 |
| F3 |  | 建筑面板 |
| F4 |  | 市场面板 |
| F5 |  | 军事面板 |
| F6 |  | 外交面板 |
| F7 |  | 技术面板 |
| F8 |  | 文化面板 |
| F9 |  | 人口面板 |
| F10 |  | 日志 |
| F11 |  | 日志 |
| Q |  | 总账 |
| ⇧Shift+F1 |  | 大纲 |

### 地图透镜按键

这些按键用于控制各种地图透镜（lens）。

| 按键 | 图标 | 功能 |
|---|---|---|
| Alt+1 |  | 生产透镜 |
| Alt+2 |  | 政治透镜 |
| Alt+3 |  | 外交透镜 |
| Alt+4 |  | 军事透镜 |

### 其他 HUD 控制

这些按键用于打开 HUD 的其他特定元素。

| 按键 | 功能 |
|---|---|
| F | 打开地点查找器 |
| B | 打开建造队列 |
| ^Ctrl+B | 暂停/取消暂停建造队列 |
| E | 打开当前局势 |
| G | 前往详情 |
| 🏠 Home | 居中显示首都地区 |

### 标签页/窗口导航

这些按键用于在已打开的标签页或事件窗口中进行导航。

| 按键 | 功能 |
|---|---|
| ⇧Shift+1 | 打开标签页 1 |
| ⇧Shift+2 | 打开标签页 2 |
| ⇧Shift+3 | 打开标签页 3 |
| ⇧Shift+4 | 打开标签页 4 |
| ⇧Shift+5 | 打开标签页 5 |
| Page Up | 向上滚动 |
| Page Down | 向下滚动 |
| C | 确认 |
| ⎋Esc | 关闭当前窗口 |
| 鼠标按键 4 | 后退 |

### 游戏控制

这些按键用于控制其他各种游戏设置

| 按键 | 功能 |
|---|---|
| ␣ 空格或鼠标按键 5 | 暂停控制 |
| = 或数字小键盘 + | 提高速度 |
| - 或数字小键盘 - | 降低速度 |
| 1 — 5 | 设置游戏速度 1—5 |
| W ↑ A S D 或 ← ↓ → | 滚动地图视图 |
| ⇆Tab | 查看地图概览 |

### 音乐控制

这些按键用于控制音乐播放器

| 按键 | 功能 |
|---|---|
| 数字小键盘 8 或 Audio Play | 播放/暂停音乐 |
| 数字小键盘 9 或 Audio Next | 下一首音乐 |
