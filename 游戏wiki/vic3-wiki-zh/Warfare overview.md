## 编队

一个国家的军事力量被组织为*编队*：陆军和舰队。每个编队包含若干单位，且只能由一名指挥官率领。新单位和指挥官通过编队招募。每个编队都有一个本土总司令部（HQ，战略区域），除已动员的陆军外可随时更改。此外，编队也可以驻扎在其他总司令部。本土总司令部与驻扎在外的主要区别在于：编队驻扎在本土总司令部时获得**−50%**的损耗减免。

陆地编队——*陆军*——可以驻扎在总司令部或前线。在前线，陆军可以推进或防御。陆军必须动员后才能进驻前线并参与战斗。没有将军的陆军仍可防守前线，但在超过 10 个营后会受到惩罚。

海军编队——*舰队*——可以驻扎在总司令部或海区节点。驻扎在总司令部的舰队不参与任何战斗。在海区节点，舰队可以拦截、袭击运输船队、护航或封锁。舰队始终处于动员状态，且必须有一名海军上将被部署到海区节点。

### 组织度

编队拥有一个组织度数值，范围从 0% 到 100%，但通常不低于 25%。更改[动员选项](Land warfare.md)或最大组织度降低会减少组织度。当编队超出指挥上限、特殊单位超过 50%，或受到补给惩罚时，最大组织度会降低。低组织度会削弱军事单位的效能。惩罚在组织度**100%**时为零，在**0%**时达到以下完整惩罚：

- **−75%** 进攻
- **−75%** 防御
- **−75%** 封锁强度
- **−100%** 士气恢复
- **−50%** 恢复速率
- **−75%** 运输船队袭击效率
- **−75%** 运输船队护卫防御

当编队不在行军中时，若组织度低于最大值，每天恢复**1%**（依据 /Victoria 3/game/common/static_modifiers/00_code_static_modifiers.txt 中的 base_values，即“100 天达到最大组织度”——是此前文档记载的 0.5% 的两倍），超出指挥上限时恢复量降低。“军事统计”技术仍会将组织度增益提高**+20%**——基础下达到每天**1.2%**。

若组织度高于最大值，每天损失当前数值的 5% 或 1（取较高者）。

被放逐的编队最大组织度为 0。

## 军事单位

参见：
军事建筑
《维多利亚3》中的军事单位分为由兵营和征兵中心产生的陆地单位——营，以及由海军基地产生的海军单位—— flotilla（小型舰队）。营又进一步分为常备单位*正规军*和仅在战时征召的*征召兵*。

每个单位都有一个与其建筑每级就业相关的*人力*值，上限为 1000。它还有一个*士气*百分比值，会在战斗后恢复，最高至编队的补给水平。其他属性，如进攻和防御，主要取决于单位类型。单位会自动分配到其招募所属的编队，除战斗中外，可随时转移至其他编队。

当正规军和舰队单位加入编队时，其兵营或海军基地会加入建造队列并像其他建筑一样正常建造。当征召兵加入陆军时，征兵中心会立即添加到州中。每个建筑等级雇用 1000 人，由士兵和军官分摊；在满员就业时，建筑每级生产一个单位。雇用人员所需的时间即*训练速率*，它随更先进的*训练*和*海军学说*生产方式而提升。

### 单位类型

参见：
陆地单位
，
海军单位
营和 flotilla 现在各分为四类（1.9 版本时各为三类）。营可以是*步兵*、*炮兵*、*骑兵*或*海军陆战队*（海军陆战队是新单位——不受其他单位遭受的登陆效率惩罚影响）。它们又进一步细分为由[军事技术](Military technology.md)解锁的类型。类似地，flotilla 可以是*主力舰*、*巡洋舰*、*雷击舰艇*或*补给舰*——并非此前文档所记载的“轻舰”/“主力舰”/“辅助舰船”，与当前 /Victoria 3/game/common/ship_groups 的名称一致；同样进一步细分为类型。

每个单位的基础属性取决于其类型。通常，一种单位类型可以升级为更先进的类型。升级单位会使其解除动员，然后——若编队已动员——重新动员。已动员编队每周只能升级一定比例的单位：陆军**10%**，舰队**5%**。升级后的单位会失去一级资历等级及当前经验（升级前拥有 300/400 经验的老兵单位，升级后变为 0/200 经验的久经沙场单位）。

### 威望商品

使用威望商品的单位会依据威望商品的投入占比获得加成。在威望商品投入占比为 100% 时，单位获得以下加成：

- **+15%** 进攻
- **+15%** 防御
- **+25%** 士气恢复

该加成随使用百分比按比例降低。威望商品投入占比为 50% 的单位将获得上述效果的 50%。

### 实力投射

| 实力投射威望 |  |
|---|---|
| 陆军 | 0.03 |
| 海军 | **0.006**（原为 0.1） |
| 附属国陆军 | 0.0005 |
| 附属国海军 | 0.01 |

实力投射代表一个国家军事力量的震撼程度。对于**陆军**，其计算方式仍为每个单位的进攻与防御平均值乘以其人力比例（除数 1000）。对于**海军**，这随着舰船属性重做而改变——舰船不再有进攻/防御属性，因此舰船实力投射现在改为由**0.33**× 船体伤害 + **0.33**× 船员伤害 + **0.33**× 装甲 + **0.1**× 最大生命值计算。相应地，海军每点实力投射的威望乘数从 0.1 削减至**0.006**（新体系下舰船属性数值大得多，例如仅生命值就达数千，因此每点比率必须缩小以保持总威望产出相当）——陆军侧威望比率（0.03）和两个附属国比率均未改变。所有单位实力投射之和即为该国的总实力投射。这会带来多种收益；最明显的是威望和已宣布的利益。威望获取方式如右表所示；“每 100 点海军实力投射增加一个利益”的阈值无法针对新的舰船实力投射规模进行独立验证。

## 前线与战区

点击前线会打开前线的详细视图，显示双方部署的陆军及其已下达的命令。
当一个国家卷入外交博弈或战争时，*前线*会出现在盟友与敌方领土之间的每一段边界上。每对*战区*——由冲突一方控制的连片领土——之间会形成一条前线。

如果边界上的“中断”，如海洋或中立国，双方在同一国家内绕过中断继续接壤，则不视为中断，例如[俄罗斯](Russia.md)与[奥斯曼帝国](https://vic3.paradoxwikis.com/Turkey)在黑海周边的情况。如果中断将同一侧的不同国家隔开，例如[巴西](Brazil.md)与[玻利维亚](Bolivia.md)和[阿根廷](Argentina.md)交战时可能发生的情况，则会形成单独的前线。但如果潜在分离的前线之间只隔着一个州区域，它们会被连接在一起，即使这会在同一州的两侧形成相连的前线。

前线逐州推进。每赢下一场战斗，获胜一方获得*占领*分数。该分数会控制前线沿线上某个州的一定百分比。当一个州被一方完全占领时，前线会移动以纳入该州。此时，前线可能合并、分裂或完全消失。如果一条前线不复存在，被分配到该前线的陆军会自动行军至另一条前线或返回总司令部，通常是最近的那个。

## 入侵

参见：
海上入侵
陆地入侵需要一支陆军以及沿途每个中立国的军事通行权才能执行。如果陆军从当前驻地前往目的地需要超过 30 天，则无法发起入侵（对于长距离，可能需要先动员陆军以享受潜在的速度加成）。

一旦入侵计划确立，目标州会形成一条前线，防御方和进攻方都可以向这条前线增派陆军（30 天行军时间规则不再适用）。驻扎在该区域总司令部的防御方陆军**不参与**陆地入侵的防御。被分配执行入侵的进攻方陆军在入侵结束或取消之前不能被移除，其营也不能被调离。

首支入侵陆军抵达后，战斗需要两周才会开始，这给防御方提供了一个调兵增援入侵点的时间。

如果进攻方在目标州领土占领度为 0% 时输掉三场战斗，入侵即告失败，入侵陆军必须返回友方总司令部。所有防御方陆军也将返回其最近的友方总司令部。

目标州被完全占领后，入侵成功，形成一条新的常规前线。

海上入侵需要一支舰队和一到两支陆军。这些陆军可以是搭载在舰队上的海军陆战队，也可以是为此临时运送的常规陆军，或两者兼有。如果陆军的实力投射低于该州的海上要塞入侵防御值，则无法发起海上入侵。

入侵确认后，若选定的是常规陆军，舰队会先与它在友方沿海州会合，然后前往与目标州相邻的海区节点。入侵要继续进行，该海区节点必须无争议以建立滩头阵地。若有防御方舰队（实力投射至少为进攻方舰队的 25%）部署在那里，该海区即为*有争议*。陆军一旦登陆，争夺该海域便不再有影响。

战斗需要两周才会开始。驻扎在该区域总司令部的防御方陆军**确实参与**海上入侵的防御。但在发生多次入侵时，最好为每次入侵专门分配陆军，因为驻扎的陆军可能将其所有营投入单一战斗，从而使其他入侵点无人防守。

每有一个非海军陆战队类型的入侵营，就会受到**−25%**攻击的*海上入侵效率*惩罚。

如果入侵舰队输掉任何一场海战，或陆军在目标州领土占领度为 0% 时输掉三场战斗，海上入侵即告失败。随后陆军和舰队返回其本土总司令部。

目标州被完全占领后，入侵成功，形成一条新的常规前线。

### 海上要塞

[海上要塞](https://vic3.paradoxwikis.com/Naval_Fortification)可加固沿海州以抵御海上突击和海上入侵。它们提供对海上入侵、封锁和炮击的抵抗力。

- 进攻（Advance）命令指示将军尝试占领敌方控制的领土；当前线没有战斗发生时，向下一次进攻推进的进度每天累积。当进度达到 100 时，陆军会与任何敌方陆军交战，或在无抵抗时推进占领。如果双方都在进攻，通常会导致交替攻击。持有进攻命令的将军仍会防御推进中的敌军。
- 防御（Defend）命令指示将军阻止敌方推进。受命防御的将军可以收复己方领土，但绝不会占领敌方领土。

如果将军的陆军没有被指派到前线，命令不会产生任何效果。

## 动员

另见：
动员选项
可以一次性动员全部陆军，也可以逐支动员。逐支动员陆军会显示该陆军动员选项对预算的预估成本，但不会估算基础维护费增加的影响。

要给陆军下达命令，必须先将其动员。动员需要 5 到 20 天，取决于州的基础设施等因素。

与陆军不同，舰队始终处于激活状态，不需要动员。

### 征兵

与动员类似，*征召*（conscript）营可以在外交博弈或战争期间逐支陆军激活。征召兵在激活时才被雇佣，而不是作为常备单位受雇，并且需要一些时间才能完全动员。一旦激活，征召兵在动员期间无法返回平民生活。可用征召兵的数量主要取决于国家的[陆军模式法律](Power structure laws.md)及其各州的人口。许多因素会影响征兵率，例如未整合州会有 **−50%** 的征兵惩罚。

### 复员

陆军可以随时手动复员。以此方式复员一支陆军会产生一笔 90 天内衰减的费用，数额等于该陆军单位的动员成本，且该陆军在 90 天过去之前无法重新动员。当国家处于和平状态且未参与任何外交博弈时，所有陆军都会免费复员。复员的陆军会自动返回其本土总司令部（HQ）。

## 补给

在这场英国与西班牙的战争早期，消耗（attrition）造成的损失远超战斗损失。
在海外作战的编队依靠[补给网络](https://vic3.paradoxwikis.com/Supply_network)来保持装备和补给充足。如果敌方舰队袭击补给网络、击沉运输船队，就会影响编队的补给，并直接影响单位的士气恢复。例如，如果袭击使补给网络的效率降低了 2%，那么海外单位的士气恢复为 98%。如果补给降到 95% 以下，还会对组织度施加同等惩罚。例如，一个补给为 80% 的单位将受到 20% 的最大组织度惩罚。

此外，单位所属建筑的[短缺](https://vic3.paradoxwikis.com/Shortage)会将编队补给降低到同样的结果。

### 消耗

所有已动员的编队都会受到消耗影响，导致人口受伤和死亡。其影响可能相当可观，甚至超过战斗造成的伤亡数量。编队驻扎在本土总司令部时消耗降低 **−50%**。

基础消耗为 **10%**，消耗造成的伤亡每周在 **4%** 到 **12%** 之间。

正在参与战斗的营暂时不会受到消耗。

## 战斗属性

|---|---|

陆军和海军单位都使用一系列属性来影响战斗。这些属性主要由单位类型决定，但会受到许多因素的累加或修改，例如指挥官命令、技术等。

主要战斗属性是*进攻*（offense）或*防御*（defense）。进攻方编队中的单位使用进攻，防御方编队中的单位使用防御。这些属性提高单位在战斗中造成的伤亡和士气伤害。

*士气*（Morale）表示一个单位中能够继续战斗的人力百分比。每个单位都有基础*士气损失*（morale loss），在战斗中每个刻度都会降低单位士气，此外还有敌方单位造成的士气伤害。不在战斗中时，士气每天缓慢恢复，基础值为 3%，并受*士气恢复*（morale recovery）修正。

*人力*（Manpower）代表组成一个单位的个体。每个单位最多有 1000 人力，直接对应于产生该单位的建筑中受雇的人口。*伤亡*（Casualties）是单位因*消耗*或战斗造成的人力损失。战斗伤亡者要么成为受抚养者，要么死亡，死亡几率在 0.1% 到 0.5% 之间。死亡几率随敌方*击杀率*（kill rate）提高，随单位*恢复率*（recovery rate）降低。每个单位每个刻度最少有 5 人伤亡，军官的伤亡比士兵少 50%。

## 战争支持度

|---|---|

在这场战争中，法国处于劣势，主要因为其对手控制了其 50% 的战争目标。控制战争目标往往是赢得战争的关键。
法国决定止损并谈判白和，而不是拖延一场代价高昂的战争。这之所以可能，只是因为 Adagh 的战争支持度也很低。
当战争开始时，每个参战国有 **+100** *战争支持度*（war support）。每周，每个国家都会因*厌战*（exhaustion）而损失一定量的战争支持度，其数值取决于多种因素，如战争伤亡、占领百分比和激进派人口百分比。

| 厌战 | 原因 |
|---|---|
| **+0.2** | 基础增长 |
| **+1** | 敌方控制所有战争目标（按百分比缩放） |
| **+0.015** | 每有 1% 的人口为激进派 |
| **+0.1** | 每 10%（缩放）相对最大军事人力的伤亡，未输掉任何战斗 |
| **+0.4** | 每 10%（缩放）相对最大军事人力的伤亡，输掉所有战斗 |
| **+0.1** | 战争双方每 10% 的文化伤亡[2] |
| **+0.01** | 每百分之一反对战争的游说团体的政治力量 |
| **+0.01** | 每百分之一支持战争的游说团体的政治力量 |
|  | 占领百分比（仅取最高值） |
| **+0.1** | 任意（>0%） |
| **+0.5** | 高于 10% |
| **+1.0** | 高于 25% |
| **+2.0** | 高于 50% |
| **+3.0** | 高于 75% |
| **+10** | 高于 90% |

一个国家的战争支持度不会低于 **0**，除非敌方占领了所有战争目标或该国首都所在州。未被战争目标指向的国家没有这一限制，会按预期自动降至 0 以下。指向附属国的战争目标视为指向其宗主国。

### 投降

一旦一个独立国家的战争支持度达到 **−100**，它将自动投降。针对它的所有战争目标都会被强制执行，并且它退出战争。国家也可以选择在战争期间任何时候自愿投降。附属国不能选择投降，除非其宗主国投降，否则也不会自动投降。

当一个国家投降时，如果仍有战争目标存在，战争将继续。如果交战一方的所有国家都被完全占领，这些国家全部立即投降。

### 和平谈判

除投降外，还可以通过选择任一方的[战争目标](https://vic3.paradoxwikis.com/War_goals)来决定坚持或不坚持，以谈判和平。每个拥有战争目标或被战争目标指向的独立国家——即*谈判参与方*——都必须同意和平协议，这使得在盟友支持下将其抛下变得困难。

没有且未被任何战争目标指向的国家以及附属国，对和平协议没有发言权。

无法只与部分敌国谈判和平协议；任何谈成的和平协议都会结束整场战争。
