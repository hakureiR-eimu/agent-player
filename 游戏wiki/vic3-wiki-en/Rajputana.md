**Rajputana** is a [formable country](https://vic3.paradoxwikis.com/Formable_country) in western India.

Rajputana can form [India](India.md) (BHT).

## Formation

Rajputana can be formed by the following countries when they fully own the sole core state, Rajputana.

|---|---|---|---|---|---|---|

| **Bikaner** | Rajputana | Rajput | Hindu | Principality | Unrecognized | Split state in Rajputana |

## Rajput minors

| ![Ambox outdated info.png](https://central.paradoxwikis.com/images/thumb/6/65/Ambox_outdated_info.png/22px-Ambox_outdated_info.png) | Please help with verifying or updating this section. It was last verified for version 1.12. |
|---|---|

The Rajput minors are all unrecognized powers and have similar basic stats, starting technology, and politics. Each starts with a split state in Rajputana and each is a puppet of [East India](East India.md). They are all Principalities and Hindu. They generally start with the Zamindars in government with the Hindu Priesthood, Armed Forces, Intelligentsia, and Ryots in opposition, and the remaining interest groups marginalized.

The Hindu Priesthood has the Hindu Moralist ideology instead of the default Moralist. The Petite Bourgeoisie has the Modernizer ideology instead of the default Reactionary. The Intelligentsia has the Constitutionalist ideology instead of the default Republican.

They all start with the following technology and laws:

| Production technology | Military technology | Society technology |
|---|---|---|
| Prospecting Steelworking Distillation | Drydocks Admiralty Military Drill Artillery | International Trade Centralization International Relations Democracy |

| Power Structure | Economy | Human Rights |  |  |  |
|---|---|---|---|---|---|
| Governance Principles | Monarchy | Economic System | Traditionalism | Free Speech | Right of Assembly |
| Distribution of Power | Autocracy | Trade Policy | Mercantilism | Labor Rights | No Workers' Rights |
| Citizenship | Subjecthood | Taxation | Land-Based Taxation | Children's Rights | Child Labor Allowed |
| Caste Hierarchy | Caste Not Enforced | Land Reform | Tenant Farmers | Rights of Women | Legal Guardianship |
| Church and State | State Religion | Colonization | No Colonial Affairs | Welfare | No Social Security |
| Bureaucracy | Hereditary Bureaucrats | Policing | No Police | Migration | Migration Controls |
| Army Model | Professional Army | Education System | No Schools | Slavery | Debt Slavery |
| Internal Security | No Home Affairs | Health System | No Health System | Labor Associations | Guild System |

Bikaner starts with somewhat different laws; it does not start with British Indian Caste System, but gains it shortly after the start:

| Power Structure | Economy | Human Rights |  |  |  |
|---|---|---|---|---|---|
| Army Model | Peasant Levies | Land Reform | Serfdom | Slavery | Debt Slavery |
