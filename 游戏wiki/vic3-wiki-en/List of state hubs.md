This is a list of all hubs by [state regions](List of state regions.md) in the game. There are five types of hubs: city, port, mine, farm, and wood. Each state can have at most one of each type, but many states lack one or more hubs, and inland states never have a port. Hubs appear on the map only when a relevant building has been built in a state region. If the hubs in a state region are owned by different countries, there is no gameplay effect. Hub locations are defined in the /Victoria 3/game/map_data/state_regions files, and hub names are found in /Victoria 3/game/localization/english/hub_names_l_english.yml.[1]. This list uses the default names; many hubs and states have dynamic names based on the owner or other criteria.
