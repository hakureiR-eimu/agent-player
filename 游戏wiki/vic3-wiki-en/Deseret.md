**Deseret** is a [releasable country](https://vic3.paradoxwikis.com/Releasable_country) in North America. It may be released by any country that controls its capital.

As a Yankee country, Deseret may form the [Free States of America](Free States of America.md) or reform the [USA](https://vic3.paradoxwikis.com/USA).

## Core states

Deseret has only one core state.

| Name | Core of | Homelands | Arable Land | Resources | State Traits |  |  |  |
|---|---|---|---|---|---|---|---|---|
| Size | Uses |  |  |  |  |  |  |  |
| Utah |  | Paiute | 50 | Maize Farm Livestock Ranch | 6 | 30 | (20) | Wasatch Range −10% Infrastructure |

The state of Utah gains a Yankee homeland if the [USA](https://vic3.paradoxwikis.com/USA) completes the *Manifest Destiny: Mexican Cession* journal entry.

## Achievements

Deseret is in a good position for the *Amish Paradise* achievement, since it does not start with any industry and therefore a very weak industrialist IG, thus making the law much easier to pass. Especially if Deseret is released as a [puppet](https://vic3.paradoxwikis.com/Puppet) of USA, as it can then specialize within the broader American market, using a multitude of [decrees](Decrees.md) on their single state.
