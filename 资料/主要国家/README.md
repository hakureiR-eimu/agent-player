# 主要国家资料

维多利亚3 开局（1836）主要国家名单与 tag。资料按 tag 分文件夹存放，一个国家一个文件夹；tag 是国家、文件夹、agent 三者的统一绑定标识（局文件夹下的国家文件夹同样用 tag 命名）。

## 开局主要国家（8 国）

这批国家在游戏内是开局"列强"（Great Power，最高等级），本项目统称主要国家。

| 名次 | 国家 | tag |
|---|---|---|
| 1 | 大不列颠及爱尔兰联合王国（大英） | GBR |
| 2 | 法兰西王国 | FRA |
| 3 | 俄罗斯帝国 | RUS |
| 4 | 奥地利帝国 | AUS |
| 5 | 普鲁士王国 | PRU |
| 6 | 美利坚合众国 | USA |
| 7 | 西班牙 | ESP |
| 8 | 奥斯曼帝国 | TUR |

说明：

- 游戏内列强数量不固定，由声望阈值决定；上表是当前版本（1.9）开局的名单。
- 第 1、2 名有官方 dev diary 背书；3—8 的名次为多来源拼合，最终以游戏内排行榜为准（可开一局用控制台核对）。
- 大清（CHI）开局是"未认可主要政权"，不在这批主要国家里；需要扮演时再补资料。
- tag 证据：GBR/FRA 出自官方 wiki Rank 页的开局表；AUS/ESP/RUS/TUR 出自官方 wiki 页面文件与徽章定义；PRU/USA/CHI 出自官方 wiki 与 mod 素材表交叉。

## 文件夹结构

```
资料/主要国家/
  GBR/
    介绍.md
  FRA/
```

每个国家文件夹内放该国介绍（介绍.md），开局前备好，拉起 agent 时由运行时写入局文件夹的不可变文件夹。
