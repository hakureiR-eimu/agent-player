# MVP

> 起步阶段的最小可验证目标：项目第一步要做出什么。本文档是第一步的文案，写完即固定——达成后归档，后续迭代另起各自的文档，不回写本文档。

## 目标

在一场 Victoria 3 对局中，**开局所有非玩家列强各由一个 agent 扮演**，玩家通过飞书与它们展开大国外交：

1. **角色化**：每个列强 agent 带一份角色书（国家人设、口吻、历史包袱）和国家目标（战略诉求、底线），言行有辨识度、有盘算
2. **三通道沟通**（飞书）：
   - 公屏：所有国家可见的公开表态
   - 私聊：与玩家一对一的秘密外交
   - 拉群：把若干国家拉进群的集团外交
3. **读得懂局面**：游戏状态经 mod 写入日志，**每月（游戏时间）推送给 agent**，agent 也可主动拉取最新快照；发言与决策基于真实局势
4. **做得出动作**：agent 通过**控制台命令宏**执行外交操作——第一版**仅两个**：**创造外交博弈**、**加入外交博弈**（站边），语言威胁与承诺能落地为游戏内事实

一句话：**8 个有性格的列强，在真实战局里跟你合纵连横，谈不拢就开博弈、拉人站队。**

## 验收标准（完成的定义）

- [ ] 开局所有非玩家列强均由 agent 接管外交，无一遗漏
- [ ] 每个 agent 的飞书发言符合其角色书（盲测中能被区分出是哪个国家）
- [ ] agent 的表态与游戏实际局势一致（打起来后态度确实变化，不胡说）
- [ ] 公屏 / 私聊 / 群聊三通道全部可用，秘密外交内容不泄露到公屏
- [ ] agent 能通过控制台宏成功执行两类操作：创造外交博弈、加入外交博弈（站边发起方/目标方）
- [ ] 谈判能落地：谈不拢时 agent 真的创造外交博弈、真的拉第三国站队（不是嘴上说说）；谈判过程有真实的讨价还价
- [ ] 一局至少持续到重大局势变化（如一场大战或一次联盟重组），全程 agent 不崩溃、不出戏、不失控

## 范围

### In-scope

- 非玩家列强全覆盖（约 8 个；非列强国家不接）
- 每国一份手写角色书 + 国家目标
- 飞书三通道
- 状态读取：mod 每月写日志快照，月度推送 + agent 按需拉取
- 外交操作：**仅两类**——创造外交博弈、加入外交博弈（控制台宏实现；不实现结盟/pact 等其他操作，留待后续迭代）
- 单机对局（不考虑多人）

### Out-of-scope（明确不做）

- 非列强国家、次强权
- 经济 / 内政 / 军事操作
- 宣战与战争指挥（第一版主打和平方向的外交沟通；宣战留待后续迭代评估）
- agent 之间的自主密谈（第一版 agent 只与玩家谈；agent 互谈见 brainstorm）
- 跨局记忆、信誉系统
- 语音、游戏内 UI、直播可视化
- 成本优化、多模型路由
