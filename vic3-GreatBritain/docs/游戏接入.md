# 游戏接入

一局单机维多利亚3，真人玩家玩其他国家，大不列颠由 agent 扮演：绝大多数操作留给游戏原生 AI，agent 通过 mod 接管一部分操作，被接管的部分把原生行为禁用。本文件说明游戏接入模块的组成与提供的功能。

## 在整个任务里的位置

vic3-GreatBritain 拆成三块：游戏接入（mod＋mcp-server，本文件）、game-harness（agent 的宿主与编排）、agent 本体（GreatBritain 的会话、记忆、文件夹）。后两块另有说明文件，本文件不涉及。

游戏接入模块的边界：从游戏进程到 MCP 工具为止。上游是加载了 mod 的游戏进程，下游是任意 MCP 客户端（不依赖 game-harness 存在，比如直接给 Claude Code 挂上就能用）。

## mod

mod 在 vic3-GreatBritain/mod/，是游戏内的唯一改动面，别的组件不直接碰游戏文件。提供两方面的功能：

### 读：状态导出

- 用 on_actions 挂游戏的月度钩子（候选 on_monthly_pulse 系列，以本地 wiki 镜像的 On actions、Effect 文档为准）
- 在钩子里用 log effect 往 game.log 写机器友好格式的一行行记录
- 内容两组：大不列颠摘要（财政、建造队列、法律进程、外交关系）＋世界摘要（列强榜、进行中的外交博弈与战争）

### 写：操作宏与 AI 禁用

- 白名单宏库：参数化的 scripted_effect，每个宏映射到和玩家在界面上操作同源的原生 effect，这是宏的取舍原则——不做界面之外的魔法操作
- 大不列颠被接管域的原生 AI 禁用：改 ai_strategies 的 possible 排除 GBR，或 defines 里对 GBR 特判；能切到多细取决于引擎给的口子

## mcp-server

mcp-server 在 vic3-GreatBritain/mcp-server/，TypeScript 写，是游戏侧唯一的外部操作者。它面对加载了 mod 的游戏进程，把读写包装成标准的 MCP 服务。

### 读工具

- get_monthly_state：解析 game.log 里最新一个月的记录，返回结构化数据
- list_months：历史月份索引
- 日志定位：Documents/Paradox Interactive/Victoria 3/logs/game.log，路径可配置

### 写工具

- do_action：白名单校验后，用 SendInput 把宏命令注入游戏控制台
- get_receipt：查执行回执。失败是常态，回执必须可查

## 前提与约束

- 游戏须以 -debug_mode 启动，控制台和 file watcher 才可用
- 存档可在 pdx_settings.json 里设成文本格式，mcp-server 可用它做全量校准
- SendInput 在 Claude 沙箱内失败过，注入相关验证须在用户终端做
- 写侧落地前有几个引擎行为要先验证：effect 命令带国家范围对非玩家国执行、common/ 脚本热重载范围、AI 禁用粒度

## 不在本模块内

game-harness、agent 本体、Discord 接入。
