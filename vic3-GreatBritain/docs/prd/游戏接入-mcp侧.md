# 游戏接入-mcp侧

游戏接入拆成两侧：mod 侧（[游戏接入-mod侧](游戏接入-mod侧.md)）把游戏内状态导出到 error.log，mcp 侧（本文件）把日志变成 agent 可用的方法。mcp 侧是 harness 的游戏接入子模块（接口声明见 [harness](harness.md)：读取世界局势、发起博弈两个方法，加年度通知 new_year 一个事件），Python 写、跑在 harness 进程内，是游戏侧唯一的外部通道。第一版读方法直接实现；年度通知（每年向主体发事件）随 harness 主体实现补上；写方法只声明一个——发起外交博弈（start_play），实现空置，随写侧版本补。

## 职责与边界

mcp 侧的边界：从 error.log 到两个方法为止——解析 mod 侧定义的年度记录（行格式与封闭清单见 mod 侧文档，两侧以行格式为交接面），把状态读取做成 harness 进程内的方法。不读存档（直读已否决，见[存档直读验证](../调研/存档直读验证.md)）。

## 声明：做什么

两个方法加一个事件（声明总表在 harness 文档，这里带实现语义）：

- get_state：读游戏的最新状态——各国最新一条记录拼成的世界格局快照，返回结构化数据
- start_play：发起外交博弈（写方法），实现空置——方法注册给会话，调用返回固定的"未实现"应答
- new_year：年度通知——游戏内每过一年，往事件队列推一个 new_year 事件

都以游戏在跑为前提——游戏没启动时，方法调用直接报错，年度通知不发。

## 实现：怎么做

- 日志定位：默认 Documents/Paradox Interactive/Victoria 3/logs/error.log，路径可配置；链路验证不造 mock，配置指向一份真实格式的样例日志即可单测
- 游戏在跑检测：按进程名查进程表（默认 victoria3.exe，可配置）；游戏没在跑，工具直接报错，不读日志
- 记录识别：逐行扫日志，认行内前缀 `vic3-GreatBritain `（局名前缀，mod 侧定义；行首有游戏加的时间戳/来源头），两类行：`state`（国家行）、`fin`（财政行）；行内 key=value 逐对解析、按字段名取值——year 的值是完整本地化日期（如 `12月 27, 1837`，含空格逗号），从值尾取 4 位数字为年份；数值转数字，本局记录行行尾 LF、与文件内引擎自身行的 CRLF 混存，切行须都兼容；字段含义与行格式以 mod 侧文档为准
- 残行：游戏把日志攒在内存里、攒一批才落盘，在跑文件的末行可能只有前半截——解析不出就跳过，下次读它就完整了
- 去重：同一 (tag, year) 后出现的覆盖先出现的——读档重跑同一年，以最新一次为准
- 取数与排序：每国取它最新一条记录（当年还没触发的国家自然落在上一年的记录上），拼成快照；输出前 powers 按 rank 升序排好，rank 是行内触发时点的当刻名次、可能并列；通常 16 国，席位变动时可能 15–17 国
- 无数据：游戏第一年（首次年度导出前）日志里还没有本局记录，get_state 返回空
- 年度通知：定时轮询 error.log——先看文件修改时间，变了才解析；解析出比上次已通知年份新的本局记录，往事件队列推一个 new_year 事件。间隔几秒就够：一年才触发一次，mod 记录攒批落盘，error.log 里还有引擎自己的行，精确即时没有意义，解析确认才是准的
- 接入方式：Python，harness 进程内模块——两个方法由 harness 经 SDK 的进程内 MCP 服务注册成会话工具，年度通知的事件推进 harness 的事件队列
- get_state 返回模板（`<>` 为占位）：

  ```json
  {
    "powers": [
      { "tag": <tag>, "year": <年>, "rank": <名次>, "gdp": <GDP>, "army": <营队数> }
    ],
    "gbr_finance": { "year": <年>, "gold": <金库>, "debt": <债务本金>, "week_net": <每周净收支> }
  }
  ```

  示例（实测值，国家行为 1837 年、财政行为 1836 年开局——两条年份不同正是"每国取最新一条"的常态；powers 通常 16 国、1837 年 GBR rank=1，此处截短）：

  ```json
  {
    "powers": [
      { "tag": "FRA", "year": 1837, "rank": 3, "gdp": 24109387.47464, "army": 282 }
    ],
    "gbr_finance": { "year": 1836, "gold": 0, "debt": 440232.39442, "week_net": -108278.71675 }
  }
  ```

## 前提

- 存档可在 pdx_settings.json 里设成文本格式，mcp-server 可用它做全量校准
