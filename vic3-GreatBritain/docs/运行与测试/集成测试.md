# 集成测试

怎么验证这套东西：局部——每个子模块的集成测试，是测试文件，在 VSCode 里跑；全局——整个系统的集成测试，没有测试文件，是真正把系统跑起来，人去操作、观察过程和结果。

## 集成测试与自动测试的关系

- 集成测试直接打系统外的东西：game 打真游戏、im 打真 Discord、agent 起真 SDK 会话。因此外界前提（游戏在跑、token 填了、代理通、Claude Code 登录了）不满足时它就**失败**——这是设计出来的行为：报错写明缺什么前提，失败说的是"前提没配好"，不是代码坏了
- 命令行全量跑（`uv run pytest`）默认排除集成测试（pyproject 的 addopts 配了 `-m "not integration"`），自动测试不被它们拖红；VSCode 测试面板不受排除影响（.vscode/settings.json 的 pytestArgs 配了 `--override-ini=addopts=`），点哪个跑哪个——面板里能下断点、看输出、单步跟过程
- 单测（`uv run pytest`，面板里同样能点）仍是改完代码的底线：模块行为全验，与系统外的交互用替身（game 读真实格式的样例日志、im 用假 discord client、agent 用假会话）。替身的边界：与系统外模块的交互在集成测试里不造假——game 的集成测试读真 error.log（游戏得开着）、im 的集成测试收发真 Discord 消息、agent 的集成测试起真会话（第一项工具里 IM 两件是假的，第二项连 IM 也全真）；agent 的会话本体单测用假会话（FakeSession）是可接受的

## 局部：子模块的集成测试

都在 VSCode 测试面板里点跑（测试树按文件分组，文件路径如下）。跑的时候按 Ctrl+J 展开底部面板，print 输出（等玩家操作的提示、收到的内容）在"测试结果"页看——标签页与终端同一排；那里没有就去"输出"页右上角下拉选 Python 测试日志（Python Test Log），原始输出流在那。

### game——三大操作（get_state、start_play、new_year）

文件：[test/game/test_game_integration.py](../../test/game/test_game_integration.py)

前提：Victoria 3 在跑（[运行](运行.md)每次启动第 2 步）。游戏没跑时三个测试立即失败，报"游戏未在跑：进程表里没有 victoria3.exe"。

- **test_get_state_reads_world_situation**：调 get_state 读世界局势，结束时打印读出的记录数
- **test_start_play_returns_response**：调 start_play 发动外交博弈（写侧占位），结束时打印返回的应答
- **test_new_year_event_arrives**：起主体的年度节拍＋事件总线，收到 new_year 事件即过。error.log 已有本局记录时首轮几秒内就推（把已察觉的当前年份推出来）；新开一局第一年（日志还没有本局记录）要等游戏跑完当年——默认等 5 分钟，环境变量 INTEGRATION_NEW_YEAR_WAIT_SECONDS 可调长

### im——dm bot 收命令回回执、gbr bot 收私信回私信

文件：[test/im/test_im_integration.py](../../test/im/test_im_integration.py)

前提：config.toml 填好两个 token、代理通 Discord（[运行](运行.md)每次启动第 1 步）。token 没填：立即失败，报缺哪项。player_id 在玩家发来消息以前无从得知（值要从收到的消息里学），所以两项测试都等人先动手、bot 收到后再回话（限时 300 秒，环境变量 INTEGRATION_IM_WAIT_SECONDS 可调）：

- **test_dm_bot_replies_receipt_in_channel**：人在服务器频道 @ dm bot 下命令（开始游戏/保存游戏/结束游戏任一），dm bot 在同一频道回"收到命令：××"；测试打印"DM收到命令"后通过
- **test_gbr_bot_replies_dm_to_player**：人给 gbr bot 发一条私信，gbr bot 反向私信"收到消息：××"（player_id 用私信里带的——定向就是这么学的）；测试打印"GBR收到消息"后通过

### agent——真会话的两条回路

真会话的文件：[test/agent/test_agent_integration.py](../../test/agent/test_agent_integration.py)（前提：本机装好 Claude Code CLI；config.toml 配了模型凭证三项走它，或本机 Claude Code 已登录——两者其一）

两个测试都起真 SDK 会话：system prompt 吃项目里的 agent-system-prompt.md（会话自己读），测试指令附进临时 gbr 模板的 CLAUDE.md（SDK 装载项目指令时随手册进会话）；会话写进 gbr 根下的回执文件是验收口——等会话空闲后读出内容打印、删掉文件后通过（限时 300 秒，环境变量 INTEGRATION_AGENT_WAIT_SECONDS 可调）。

- **test_agent_reads_state_into_test_state_file**：工具里 get_state 是真的（游戏得在跑），agent 开局调它读世界局势，把结果写进自己文件夹根下的 test_state.md
- **test_agent_replies_dm_and_records_test_message**：IM 也是真的（两个 bot 在线、发消息工具直连 Discord），人在 Discord 私信 gbr bot，agent 把私信原文写进 test_message 并回私信"收到"

假会话的单测：[test/agent/test_agent_module.py](../../test/agent/test_agent_module.py)——消息队列的攒与送（空闲即送、忙时攒批合并）、私信落盘、gbr 从模板重建、收尾整理批、局外丢弃、会话已在跑报错。改 agent 代码跑它。

### 主体

装配与调度（命令分流、频道挡板、收尾顺序）单测盖住（[test/test_dispatcher.py](../../test/test_dispatcher.py)、[test/test_main.py](../../test/test_main.py)）；它的集成验证走下面的全局。

## 全局：整个系统的集成测试

不是测试文件——被测的就是运行中的系统。照[运行](运行.md)每次启动把游戏与 harness 跑起来，人在 Discord 与游戏里操作，观察三处的过程和结果：Discord 界面、harness 终端日志、gbr 文件夹。从头到尾一局，每步做什么、看到什么算对：

1. 开游戏：launcher（GreatBritainAgent playset）开一局单机新游戏，选自己的国家（非大不列颠），跑起来
2. 起 harness：日志出现"dm bot 已登录 Discord""gbr bot 已登录 Discord"
3. 开局：大厅频道 @ dm bot 下"开始游戏"——公屏落回执"开始游戏 执行完成"、服务器出现 GreatBritain 频道、日志出"建了全新的 gbr"；agent 按手册（gbr 里的 CLAUDE.md）办开局的事，Discord 上无动静（亮相等玩家先说话）。这一步验的是：命令通道收命令、建频道、建 gbr、起会话。频道已在（上次局没结束游戏）会被拒绝，先下"结束游戏"收掉再开始
4. 对话：给 gbr bot 发第一条私信（打个招呼）——日志出"gbr bot 收到私信"、gbr/world/chat/dialogue.jsonl 落一条、会话被唤醒后 gbr bot 回话亮相（他是谁、这局想干什么）。验：message 事件的整条链（进队列、落盘、唤醒会话）与私信一进一出——agent 从这条私信学到玩家的 Discord 用户 ID，之后发消息工具都定向他
5. 问世界：私信问他"现在列强都是什么家底"——他调 get_state（真工具打真游戏），回话里带真实的 GDP/军力/自家财政数字。验：get_state 接进会话
6. 发博弈：让他对某国发起外交博弈——他调 start_play，现在返回"未实现"应答、他如实转告。验：start_play 接进会话（写侧占位返回占位应答，行为是对的）
7. 过年：游戏速度拉满跑过年末——日志出"游戏进入 XXXX 年，推 new_year 事件"、会话被新年唤醒、gbr bot 私信发来年度研判（gbr/memory/ 里通常也有研判底稿）。验：新年判定节拍 → new_year 事件 → 会话的整条链
8. 翻旧账：问他"我们之前聊过什么"——他调 read_message 翻私信记录（或读 world/chat/dialogue.jsonl），回话接得上前文。验：读的能力
9. 保存：大厅频道 @ dm bot 下"保存游戏"——会话收尾批整理 memory 后结束、GreatBritain 频道留着、公屏落回执"保存游戏 执行完成"
10. 复盘：gbr 文件夹看一局的痕迹——memory/ 的账本与年度研判、world/chat/dialogue.jsonl 的完整对话（结束游戏后清空，要看趁现在）
11. 结束：@ dm bot 下"结束游戏"——频道销掉、gbr 清空，这局彻底完；再开新局回第 3 步
