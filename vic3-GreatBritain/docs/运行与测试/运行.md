# 运行

把整一套跑起来要办的活：Discord 两个 bot、游戏与 mod、harness 进程三头就位。bot 的建号、拉进服务器、玩家侧设置（一次性）细节在 [discord侧管理](../prd/discord侧管理.md)；跑起来之后怎么验证见[集成测试](集成测试.md)。

## 每次启动

按顺序三步：网络 → 游戏 → harness。

1. 网络能到 Discord：代理软件开 TUN／接管模式；没开 TUN 就确认 config.toml 的 discord_proxy 填着本地代理端口
2. 启动游戏：Paradox Launcher 选 GreatBritainAgent 这个 playset（mod 已在其中启用）→ 单机新游戏 → 人类玩家选自己的国家（大不列颠不动，是 agent 玩的）。游戏内每年年末（12 月底）mod 把世界格局写进 error.log
3. 起 harness（在 vic3-GreatBritain/ 目录）：

   ```
   uv run python -m main
   ```

   日志出现"dm bot 已登录 Discord""gbr bot 已登录 Discord"即就绪；Ctrl+C 退出，会话在跑会先按保存游戏收尾

顺序不拘——harness 先起、游戏后开也行：游戏没跑时 get_state 报错、新年判定静默返回 None，都不碍事。开局当年 12 月底 mod 才写第一条记录，此前读到的世界是空的。

之后在 Discord 里开局、对话、收档，走[集成测试](集成测试.md)的全局流程。

## 第一次启动

一次性办五件事，办完之后每次启动就只剩上面三步。

### 1. 装依赖

本机装 uv（已装跳过）：

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

在 vic3-GreatBritain/ 目录装依赖（源走清华镜像，已配在 pyproject.toml；claude-agent-sdk 的平台 wheel 上百 MB，慢是正常）：

```
uv sync
```

### 2. Discord 两个 bot

照[discord侧管理](../prd/discord侧管理.md)办：建 dm bot（主持命令）与 gbr bot（agent 的门面）、拉进同一个服务器、玩家侧允许服务器成员私信＋开开发者模式。

### 3. 写 config.toml

复制模板 config.example.toml 成 config.toml（同目录），填三项：dm_token、gbr_token（后台 Bot 页 Reset Token 抄的）、player_id（开发者模式右键自己的头像复制用户 ID）。直连不到 discord.com 的网络再填 discord_proxy；agent 会话要用 GLM（或别的 Anthropic 兼容服务）再填模型凭证三项（anthropic_base_url、anthropic_auth_token、agent_model）——不填走本机 Claude Code 的登录态；其余项省略即默认，本机默认路径已对。

### 4. 装 mod

游戏只认 Victoria 3 用户目录 mod/ 下的文件夹，把开发文件夹的 mod/ 用目录链接链过去——链接建一次，开发侧改 mod 游戏侧即生效，不用重新安装。cmd 窗口里执行（junction 不用管理员权限）：

```
mklink /J "C:\Users\ZhangJunWei\Documents\Paradox Interactive\Victoria 3\mod\vic3-greatbritain-state-export" "D:\work\game-agent\vic3-GreatBritain\mod"
```

再在 Paradox Launcher 里：Playsets 新建一个（名字随意，本机叫 GreatBritainAgent）→ All Mods 里找到 vic3-GreatBritain State Export → 加进 playset 勾启用 → 把这个 playset 设为当前用的。

### 5. agent 会话的模型

二选一：config.toml 填模型凭证三项（anthropic_base_url、anthropic_auth_token、agent_model，如 GLM 的 Anthropic 兼容入口）——agent 会话独立走它；或三项不填，走本机 Claude Code 的登录态（终端里 `claude` 能正常对话即可，没登录先走一遍登录）。
